# F17-T03: Admin panel token upload/manage UI

**Feature:** F17
**Wave:** 1
**Type:** frontend
**Depends on:** F17-T01, F17-T02
**Status:** done

## User Story

As Anderson (admin), I want to upload, remove, and reorder tokens for each collection in the admin panel, so that I can maintain which tokens accompany each deck.

## Objective

Add a "Tokens" section to the create/edit collection modals in the admin panel, following the exact same UI pattern as the sampleImages section but with an additional quantity field per token.

## Dev Notes

### Location: `admin/public/index.html`

### 1. Create Collection Modal — add Tokens section

After the sampleImages upload zone (~line 1300), add a new section:

```html
<label class="label">Tokens</label>
<div id="create-tokens-grid" class="grid grid-cols-2 sm:grid-cols-3 gap-3 mb-2"></div>
<div id="create-tokens-upload" class="upload-zone ...">
  Arraste tokens ou clique para selecionar
  <input type="file" multiple accept="image/*" onchange="previewCreateTokens(this)" hidden />
</div>
```

Each token preview card shows:
- Thumbnail image
- Text input for token name (auto-filled from filename)
- Number input for quantity (default: 1, min: 1)
- Remove button (X)

**JS functions:**
- `previewCreateTokens(input)` — preview selected files, store in `createTokenFiles[]`
- In `addCollection()`: after sampleImages upload, POST token files + names + quantities to `/api/collections/{slug}/tokens`
- Then PUT to update collection with returned token data

### 2. Edit Collection Modal — add Tokens section

After the existing sampleImages grid/upload section (~line 1619), add:

```html
<label class="label">Tokens <span id="edit-tokens-count" class="text-xs text-gold/60">0 tokens</span></label>
<div id="edit-tokens-grid" class="grid grid-cols-2 sm:grid-cols-3 gap-3 mb-2"></div>
<div id="edit-tokens-upload" class="upload-zone ...">
  Adicionar tokens
  <input type="file" multiple accept="image/*" onchange="uploadEditTokens(currentEditSlug, this)" hidden />
</div>
```

Each existing token card shows:
- Thumbnail with watermark
- Name (editable text)
- Quantity (editable number, displayed as badge)
- Delete button (calls `DELETE /api/collections/{slug}/tokens/{filename}`)
- Move up/down buttons for reorder

**JS functions:**
- `renderEditTokens(slug, tokens)` — render grid from collection.tokens
- `uploadEditTokens(slug, input)` — POST new tokens, merge with existing
- `removeToken(slug, filename)` — DELETE endpoint, optimistic UI
- `moveToken(slug, fromIdx, toIdx)` — PUT reorder endpoint
- `updateTokenQuantity(slug, filename, qty)` — inline edit, PUT collection update

### 3. UI Style

Follow existing admin patterns exactly:
- Same `.card` styling for token tiles
- Gold border on hover
- Upload zone with dashed border and gold accent
- Number input styled with `.input` class
- Toast notifications on success/error
- Responsive grid: 2 cols mobile, 3 cols desktop

## Testing

- **Happy path:** Upload 3 tokens with names and quantities, see them in grid
- **Happy path:** Edit quantity inline, verify persistence
- **Edge case:** Upload token with no name (should auto-generate from filename)
- **Edge case:** Remove all tokens from a collection
- **Error scenario:** Upload invalid file type shows error toast
- **Boundary:** Reorder tokens with drag-like up/down buttons
