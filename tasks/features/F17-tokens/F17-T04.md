# F17-T04: Landing page token button + modal

**Feature:** F17
**Wave:** 1
**Type:** frontend
**Depends on:** F17-T01, F17-T02
**Status:** done

## User Story

As a customer browsing a collection, I want to see which tokens come with the deck and how many of each, so that I know exactly what I'm getting.

## Objective

Add a tokens trigger button on the collection detail page (between the card grid and the DeckCheck/Manual links) and a modal that displays all tokens with their quantities.

## Dev Notes

### 1. TokensModal component — `src/components/tokens-modal.tsx` (new)

Create a modal component following the existing Lightbox pattern:

```typescript
type TokensModalProps = {
  tokens: Token[];
  isOpen: boolean;
  onClose: () => void;
};
```

**Modal design:**
- Overlay: black 90% opacity + backdrop blur (same as Lightbox)
- Body scroll locked when open
- Close on Escape key + click outside + X button
- Z-index: 100 (same as Lightbox)

**Modal content:**
- Title: "Tokens do Deck" in Cinzel font, gold color
- Grid: 2 cols mobile, 3 cols tablet, 4 cols desktop
- Each token card:
  - Image wrapped in `Card3DTilt` (same 3D effect as sample cards)
  - Right-click disabled on image
  - Token name below image (Jost font, white)
  - Quantity badge: gold circle with "x3" format, positioned at top-right corner of image
- Fade-in animation (match Lightbox: 0.2s ease-out)

**Styling must match site theme:**
- Dark background (`oklch(0.13 0.012 265)` / surface colors)
- Gold accents for title and quantity badges
- Rounded corners (2xl)
- Subtle border with gold tint

### 2. Token trigger button — `src/routes/colecoes.$slug.tsx`

Insert AFTER the card grid section (after the disclaimer text, ~line 143) and BEFORE the DeckCheck/Manual links section (~line 145):

```tsx
{collection.tokens && collection.tokens.length > 0 && (
  <section className="text-center py-8">
    <button
      onClick={() => setTokensOpen(true)}
      className="inline-flex items-center gap-3 px-6 py-3 rounded-2xl border border-gold/30 bg-gold/5 hover:bg-gold/10 hover:border-gold/60 transition-all duration-300 group"
    >
      {/* Token icon — use Lucide's Coins or Sparkles icon */}
      <Coins className="w-6 h-6 text-gold group-hover:scale-110 transition-transform" />
      <span className="font-display text-gold text-lg">
        Ver Tokens ({collection.tokens.length})
      </span>
    </button>
  </section>
)}
```

Add state:
```tsx
const [tokensOpen, setTokensOpen] = useState(false);
```

Render modal:
```tsx
{collection.tokens && collection.tokens.length > 0 && (
  <TokensModal
    tokens={collection.tokens}
    isOpen={tokensOpen}
    onClose={() => setTokensOpen(false)}
  />
)}
```

## Testing

- **Happy path:** Collection with 3 tokens shows button, clicking opens modal with all 3
- **Happy path:** Quantity "x3" badge displays correctly
- **Edge case:** Collection with 0 tokens — button not shown
- **Edge case:** Collection with tokens but all quantity=1
- **Edge case:** Modal close via Escape, click outside, X button
- **Boundary:** Many tokens (10+) — scroll within modal
- **Visual:** 3D tilt effect works on token cards
- **Visual:** Responsive grid adapts to screen sizes
