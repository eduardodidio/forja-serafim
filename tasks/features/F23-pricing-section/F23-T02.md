# F23-T02 — Admin API: pricing CRUD + settings origin fields

**Status:** planned
**Wave:** 1
**Depends on:** —

## User Story

As Anderson (admin), I need API endpoints to read and update pricing data and origin address so the admin panel can manage all values without code changes.

## Dev Notes

### 1. Add `PricingProduct` and `PricingData` types to `admin/src/server.ts`

```ts
type PricingProduct = {
  id: string;
  label: string;
  subtitle: string;
  icon: string;
  standardPrice: number;
  foilPrice: number | null;
  unit: string;
  highlight: boolean;
  visible: boolean;
  order: number;
};

type ShippingRegion = {
  region: string;
  states: string[];
  pacPrice: number;
  pacDays: string;
  sedexPrice: number;
  sedexDays: string;
};

type PricingData = {
  products: PricingProduct[];
  notes: string[];
  shippingRegions: ShippingRegion[];
};
```

### 2. Extend `Settings` type

```ts
type Settings = {
  whatsappUrl: string;
  originCep: string;
  originAddress: string;
};
```

### 3. New API endpoints

| Method | Path                       | Description                                      |
| ------ | -------------------------- | ------------------------------------------------ |
| GET    | `/api/pricing`             | Return full `pricing.json`                       |
| PUT    | `/api/pricing`             | Replace full `pricing.json` (validate structure) |
| PUT    | `/api/pricing/product/:id` | Update a single product by id                    |
| PUT    | `/api/pricing/notes`       | Update the notes array                           |
| PUT    | `/api/pricing/shipping`    | Update the shipping regions array                |

### 4. Extend existing `PUT /api/settings`

Accept `originCep` and `originAddress` fields alongside `whatsappUrl`:

```ts
if (body.originCep !== undefined) settings.originCep = body.originCep;
if (body.originAddress !== undefined) settings.originAddress = body.originAddress;
```

### 5. Import `PRICING_JSON` from paths

Add import and use `readJson`/`writeJson` with `gitPersistDebounced` (same pattern as collections).

### 6. Validation

- Product `id` must be a non-empty string
- Prices must be non-negative numbers (or null for foilPrice)
- `originCep` must match `/^\d{5}-?\d{3}$/`
- Use `safeHandleRequest` wrapper for all new endpoints
