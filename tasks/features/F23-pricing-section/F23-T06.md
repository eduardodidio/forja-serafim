# F23-T06 — Admin UI: Origin address fields in Settings tab

**Status:** planned
**Wave:** 2
**Depends on:** T02

## User Story

As Anderson (admin), I want to edit the origin address (CEP and street) in the Settings tab so the shipping simulator uses my current address.

## Dev Notes

### 1. Add fields to Settings panel in `admin/public/index.html`

Below the existing WhatsApp URL field, add:

```html
<div>
  <label class="label">CEP de Origem</label>
  <input
    type="text"
    id="settings-origin-cep"
    class="input"
    placeholder="94075-300"
    oninput="onSettingsChange()"
    maxlength="9"
  />
</div>
<div>
  <label class="label">Endereco de Origem</label>
  <input
    type="text"
    id="settings-origin-address"
    class="input"
    placeholder="R. Osasco, 217 - Parque Florido, Gravatai - RS"
    oninput="onSettingsChange()"
  />
</div>
```

### 2. Update `loadSettings()`

```js
document.getElementById("settings-origin-cep").value = settings.originCep || "";
document.getElementById("settings-origin-address").value = settings.originAddress || "";
```

### 3. Update `saveSettings()`

Include new fields in the PUT body:

```js
const originCep = document.getElementById("settings-origin-cep").value.trim();
const originAddress = document.getElementById("settings-origin-address").value.trim();
// Add to fetch body: { whatsappUrl, originCep, originAddress }
```

### 4. Update `onSettingsChange()` dirty detection

Include the new fields in the comparison logic.
