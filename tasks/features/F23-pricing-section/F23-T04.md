# F23-T04 — Landing page: ShippingSimulator component

**Status:** planned
**Wave:** 2
**Depends on:** T01

## User Story

As a visitor, I want to estimate shipping cost by entering my CEP so I can know the total cost before contacting via WhatsApp.

## Dev Notes

### 1. Create `src/components/shipping-simulator.tsx`

A `ShippingSimulator` component with:

#### CEP Input

- Masked input for CEP format: `XXXXX-XXX`
- "Calcular" button
- Loading state while fetching

#### ViaCEP Integration

- Fetch `https://viacep.com.br/ws/{cep}/json/` to validate CEP
- If valid: show city + state below the input
- If invalid or error: show error message, fall back to manual region selector

#### Region Fallback

- Dropdown: "Selecione sua regiao" with options: Sul, Sudeste, Centro-Oeste, Nordeste, Norte
- Shown if ViaCEP fails or as alternative

#### Results Display

- After CEP validation or region selection, show a results card:
  - **PAC:** R$ XX — prazo estimado: X-Y dias uteis
  - **SEDEX:** R$ XX — prazo estimado: X-Y dias uteis
- Use the `shippingRegions` data to look up by state (from ViaCEP) or by selected region
- Small disclaimer: "Valores estimados. O frete final e confirmado no momento do pedido."

#### State Mapping

- ViaCEP returns `uf` (e.g., "SP"). Map UF to region using `shippingRegions[].states`.

### 2. CEP Mask Utility

Simple function to format input as `XXXXX-XXX`:

```ts
function maskCep(value: string): string {
  const digits = value.replace(/\D/g, "").slice(0, 8);
  if (digits.length > 5) return `${digits.slice(0, 5)}-${digits.slice(5)}`;
  return digits;
}
```

### 3. Style Guidelines

- Render inside a `surface-card` with gold accents
- Input styled like existing inputs (rounded-xl, border-border, focus:border-gold/60)
- Results in a sub-card or divided section
- Truck icon (`Truck` from Lucide) next to the section header
- Origin info: small muted text "Enviamos de Gravatai - RS"

### 4. Error Handling

- ViaCEP timeout: 5s, then show fallback
- Network error: show fallback region selector
- Invalid CEP (ViaCEP returns `{erro: true}`): show "CEP nao encontrado"
