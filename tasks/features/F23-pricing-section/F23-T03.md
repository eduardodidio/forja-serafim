# F23-T03 — Landing page: PricingSection component

**Status:** planned
**Wave:** 2
**Depends on:** T01

## User Story

As a visitor, I want to see a clear pricing table on the landing page so I can understand what Forja Serafim offers and how much each product costs before contacting via WhatsApp.

## Dev Notes

### 1. Create `src/components/pricing-section.tsx`

A `PricingSection` component that renders:

#### Header

- Gold label: "VALORES"
- Title: "Invista no seu deck"
- Subtitle: brief description

#### Product Cards Grid

- 2-col on mobile, 4-col on desktop (`grid sm:grid-cols-2 lg:grid-cols-4`)
- Each card shows:
  - Lucide icon (mapped from product.icon string to actual component)
  - Product label (bold)
  - Product subtitle (muted)
  - Standard price: "R$ XX" with "/deck", "/carta", or "/arte" unit
  - Foil price (if exists): "Foil: R$ XX" with gold accent
  - If `highlight: true`, add a gold border or "POPULAR" badge
- Use `surface-card` class, gold accents, `Reveal` animations

#### Notes

- Below the grid, render the notes array as small muted text with bullet points
- Include the availability/waiting list note and the individual quote note

#### CTA

- "Faca seu pedido" button linking to WhatsApp with pre-filled message:
  `"Ola! Vi os valores no site e gostaria de fazer um pedido."`

### 2. Icon Mapping

Create a simple map from string to Lucide component:

```ts
const iconMap: Record<string, LucideIcon> = {
  Swords,
  Palette,
  Layers,
  PenTool,

  Gem,
  Sparkles,
};
```

### 3. Style Guidelines

- Match existing sections (DeckListSection, ThemeBuilderSection)
- Dark background, gold accents (`text-gold`, `border-gold/60`)
- `surface-card` for product cards
- Responsive: stack on mobile, grid on desktop
- Use `Reveal` with staggered delays
- Highlighted product: `ring-1 ring-gold/40` or similar subtle emphasis

### 4. Only show visible products

Filter `products.filter(p => p.visible)` and sort by `order`.
