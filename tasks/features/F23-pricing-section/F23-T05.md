# F23-T05 — Admin UI: "Valores" tab for pricing management

**Status:** planned
**Wave:** 2
**Depends on:** T02

## User Story

As Anderson (admin), I want a "Valores" tab in the admin panel to edit product prices, labels, notes, and shipping regions without touching code.

## Dev Notes

### 1. Add "Valores" tab to `admin/public/index.html`

Follow the exact pattern of existing tabs (collections, testimonials, settings):

#### Tab Button

Add to the tab bar:

```html
<button onclick="showTab('pricing')" id="tab-pricing" class="tab-btn">Valores</button>
```

Update `TABS` array: `const TABS = ["collections", "testimonials", "settings", "pricing"];`

#### Panel: `panel-pricing`

**Products Section:**

- Accordion or card list of all products
- Each product shows:
  - `label` (text input)
  - `subtitle` (text input)
  - `icon` (dropdown: Swords, Palette, Layers, PenTool, Package, Gem, Sparkles)
  - `standardPrice` (number input)
  - `foilPrice` (number input, can be empty/null)
  - `unit` (dropdown: deck, carta, arte)
  - `highlight` (checkbox)
  - `visible` (checkbox)
  - `order` (number input)
- "Salvar Produto" button per product (calls `PUT /api/pricing/product/:id`)

**Notes Section:**

- Textarea with notes (one per line)
- "Salvar Notas" button (calls `PUT /api/pricing/notes`)

**Shipping Regions Section:**

- Table/card for each region:
  - Region name (read-only)
  - States (read-only display)
  - PAC Price (number input)
  - PAC Days (text input, e.g., "3-5")
  - SEDEX Price (number input)
  - SEDEX Days (text input)
- "Salvar Frete" button (calls `PUT /api/pricing/shipping`)
