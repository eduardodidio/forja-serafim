# F18-T01 — Retry com Exponential Backoff no Git Push

**Wave:** 1
**Status:** planned
**File:** `admin/src/lib/git-persist.ts`

## User Story

Como administrador do site, quero que o git-persist tente novamente quando
o push falhar por erro transitorio (rede, timeout, conflito temporario),
para que meus uploads de tokens e imagens nao se percam no Render.

## Dev Notes

### O que mudar

Em `doGitPersist()`, o push (linha ~128) faz uma unica tentativa. Quando
falha, o estado vai para `"error"` e os dados ficam apenas no disco local
(que e efemero no Render).

### Implementacao

1. Extrair a logica de push para uma funcao `pushWithRetry()`
2. Implementar retry com backoff exponencial:
   - Max 3 tentativas (1s, 3s, 9s de delay)
   - Apenas para erros transitorios (network, timeout, 5xx)
   - NAO retry para erros de auth (401/403) ou config
3. Entre retries, re-executar `git fetch + rebase/merge` para resolver
   divergencias que possam ter surgido
4. Manter o contrato existente: retorna `PersistResult`

### Criterios de deteccao de erro transitorio

```typescript
function isTransientError(err: unknown): boolean {
  const msg = String(err).toLowerCase();
  return (
    msg.includes("could not resolve host") ||
    msg.includes("connection timed out") ||
    msg.includes("connection reset") ||
    msg.includes("ssl") ||
    msg.includes("fetch first") || // diverged history
    msg.includes("non-fast-forward")
  );
}
```
