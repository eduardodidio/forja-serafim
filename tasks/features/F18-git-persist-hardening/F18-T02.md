# F18-T02 — Structured Logging no Git-Persist

**Wave:** 1
**Status:** planned
**File:** `admin/src/lib/git-persist.ts`

## User Story

Como desenvolvedor, quero que o git-persist emita logs estruturados com
timestamp, operacao e resultado, para que eu consiga diagnosticar falhas
nos logs do Render sem precisar reproduzir o problema.

## Dev Notes

### O que mudar

Atualmente o git-persist nao tem nenhum `console.log`. Quando falha, a
unica indicacao e o estado `"error"` no endpoint `/api/persist-status`.
No Render, sem logs, e impossivel saber o que aconteceu.

### Implementacao

1. Adicionar logs em pontos-chave de `doGitPersist()`:
   - `[git-persist] START: <description>` — ao iniciar
   - `[git-persist] STAGED: <files>` — apos git add (listar arquivos staged)
   - `[git-persist] COMMITTED: <hash>` — apos commit (mostrar short hash)
   - `[git-persist] PUSH attempt <N>/<max>` — antes de cada tentativa de push
   - `[git-persist] PUSH OK` — push bem-sucedido
   - `[git-persist] PUSH FAILED: <error>` — push falhou (com detalhes sanitizados)
   - `[git-persist] RETRY in <delay>ms` — quando vai fazer retry (T01)
   - `[git-persist] SKIP: no staged changes` — quando nao tem nada para commitar

2. Sanitizar GITHUB_TOKEN de TODOS os logs (ja existe logica similar no catch)

3. Usar `console.log` para info e `console.error` para falhas — Render
   captura ambos nos logs do servico

### Arquivos a modificar

- `admin/src/lib/git-persist.ts` — adicionar console.log/error nos pontos acima
