# F18-T03 — Persist-Status Endpoint: Historico e Detalhes

**Wave:** 2
**Status:** planned
**Files:** `admin/src/lib/git-persist.ts`, `admin/src/server.ts`, `admin/public/index.html`

## User Story

Como administrador, quero ver no painel admin um historico recente das
operacoes de git-persist (ultimas 10), para saber exatamente qual upload
falhou e poder fazer retry ou re-upload.

## Dev Notes

### O que mudar

O endpoint `/api/persist-status` retorna apenas `{ state, error }` — um
snapshot pontual. Quando o Anderson ve a mensagem de erro, nao sabe qual
operacao falhou nem quando.

### Implementacao

1. No modulo `git-persist.ts`, adicionar um array circular `recentOps`
   (max 10 entradas):

   ```typescript
   type PersistOp = {
     description: string;
     timestamp: string; // ISO
     committed: boolean;
     pushed: boolean;
     error?: string;
     retries?: number;
   };
   ```

2. Ao final de cada `doGitPersist()`, push para `recentOps` (shift se > 10)

3. Exportar `getRecentOps(): PersistOp[]`

4. Atualizar `/api/persist-status` para retornar:

   ```json
   { "state": "clean", "error": null, "recent": [...] }
   ```

5. No admin UI (`index.html`), no banner de status do git:
   - Mostrar a lista das ultimas operacoes quando expandido
   - Marcar com verde (ok) ou vermelho (erro) cada entrada
   - Botao "Retry" ja existe, manter

### Arquivos a modificar

- `admin/src/lib/git-persist.ts` — `recentOps[]`, `getRecentOps()`
- `admin/src/server.ts` — atualizar response do `/api/persist-status`
- `admin/public/index.html` — expandir banner com historico
