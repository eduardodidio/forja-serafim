# F20-T02 — Use Debounced Persist in Server Mutation Endpoints

**Wave:** 0
**Status:** done

## User Story

As an admin, I want edit and reorder operations to use debounced git persistence,
so that rapid changes do not queue up dozens of sequential commit+push cycles
that overwhelm the server.

## Dev Notes

**File:** `admin/src/server.ts`

1. Update the import at line 33 to include `gitPersistDebounced`:
   ```ts
   import { gitPersist, gitPersistDebounced, getPersistState, getLastError, getRecentOps } from "./lib/git-persist.js";
   ```

2. Change the following endpoints to use `gitPersistDebounced` instead of `gitPersist`:

   - **Line ~395** — `PUT /api/collections/:slug` (edit collection metadata/tokens):
     Change `gitPersist(\`Editar colecao: ${slug}\`)` to `gitPersistDebounced(\`Editar colecao: ${slug}\`)`
