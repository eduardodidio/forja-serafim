**Wave:** 0

## User Story

As the site owner, I want the landing page features section to accurately describe my service (personalization + premium printing, not hand-drawn art), so that customers understand what I offer without implying I have a manual illustrator on staff.

## Dev Notes

### File: `src/routes/index.tsx` (line 109)

**Current copy:**
```ts
{ icon: Brush, t: "Arte autoral", d: "Cada carta desenhada e diagramada a mao." },
```

**Problem:** "Arte autoral" and "desenhada a mao" imply a human artist is drawing each card. The real service is: the customer picks a card/theme, Anderson uses AI tools + design to create the art, then prints on premium stock. They can also print any edition the customer wants.

**New copy (suggested — developer should refine for natural Portuguese):**
```ts
{ icon: Brush, t: "Arte personalizada", d: "Escolha o card e nos fazemos acontecer. Design exclusivo para o seu deck." },
```

The title should NOT use "autoral" (implies original authorship). Alternatives: "Arte personalizada", "Sua arte, seu deck", "Arte sob medida".

The description should convey: you pick what you want, we produce it. No claim of manual drawing.
