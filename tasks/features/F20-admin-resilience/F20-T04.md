## User Story

As an admin, I want quantity changes to be debounced before sending to the server
and transient 502 errors to be retried automatically, so that I get a smooth
editing experience without error toasts flashing during rapid edits.

## Dev Notes

**File:** `admin/public/index.html`

### Part A: Debounce quantity input (client-side)

1. Add a debounce utility near the top of the `<script>` block (after line ~888):
   ```js
   // Debounce utility — returns a function that delays invoking fn until
   // after `ms` milliseconds have elapsed since the last invocation.
   function debounce(fn, ms) {
     let timer = null;
     return function (...args) {
       clearTimeout(timer);
       timer = setTimeout(() => fn.apply(this, args), ms);
     };
   }
   ```

2. Create a debounced wrapper for `updateTokenQuantity` (after the function definition at line ~2107):
   ```js
   // Map of "slug:filename" -> debounced updater
   const _qtyDebouncers = {};
   function debouncedUpdateTokenQuantity(slug, filename, qty) {
     const key = `${slug}:${filename}`;
     if (!_qtyDebouncers[key]) {
       _qtyDebouncers[key] = debounce((s, f, q) => updateTokenQuantity(s, f, q), 500);
     }
     _qtyDebouncers[key](slug, filename, qty);
   }
   ```

   the debounced version:

### Part B: Retry on 502 in apiFetch

4. Modify `apiFetch` (line ~893) to retry once on 502:
   ```js
   async function apiFetch(url, opts) {
     let res = await fetch(url, opts);

     // Retry once on 502 (transient — server busy with git operations)
     if (res.status === 502) {
       await new Promise(r => setTimeout(r, 2000));
       res = await fetch(url, opts);
     }

     if (res.status === 401) {
       toast("Sessao expirada. Redirecionando para login...", "error");
       setTimeout(() => { window.location.href = "/login"; }, 1500);
       throw new Error("Sessao expirada");
     }
     // After a successful mutation, check persist status with a short delay
     const method = ((opts && opts.method) || "GET").toUpperCase();
     if (MUTATION_METHODS.includes(method) && res.ok) {
       setTimeout(() => checkPersistStatus(), 500);
     }
     return res;
   }
   ```
