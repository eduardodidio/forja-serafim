# Task F06-T01 — Adicionar campo hidden ao modelo Collection

**Feature:** F06
**Wave:** 0
**Type:** backend
**Depends on:** (none)
**Status:** planned

## User Story

As the store owner, I want to hide a collection from the public site without deleting it, so that I can temporarily remove it and bring it back later.

## Objective

Adicionar campo `hidden: boolean` ao tipo Collection nos dados e na API.

## Dev Notes

### Modelo de dados
- File: `src/data/collections.json` — adicionar `"hidden": false` a cada colecao existente
- File: `src/lib/store-data.ts` — adicionar `hidden: boolean` ao tipo Collection
- File: `admin/src/server.ts` — adicionar `hidden: boolean` ao tipo Collection (linha ~63)

### API changes
- `PUT /api/collections/:slug` — aceitar campo `hidden` no body
  - Adicionar em server.ts linha ~230: `if (body.hidden !== undefined) col.hidden = body.hidden;`
- `POST /api/collections` — default `hidden: false` para novas colecoes
  - Adicionar em server.ts linha ~207: `hidden: body.hidden ?? false,`

### Retrocompatibilidade
- Colecoes existentes sem campo `hidden` devem ser tratadas como `hidden: false`
- No store-data.ts, o filtro vai usar `c.hidden !== true` (nao `=== false`) para seguranca

## Testing

- Manual: criar colecao via API, verificar que `hidden: false` esta presente
- Manual: PUT com `{ "hidden": true }`, verificar que persiste no JSON

## Acceptance criteria

- [ ] Campo `hidden` existe no tipo Collection (ambos os arquivos)
- [ ] JSON atualizado com `hidden: false` em todas as colecoes
- [ ] API PUT aceita e persiste campo `hidden`
- [ ] API POST default `hidden: false`
