# Task F06-T02 — Botao ocultar/exibir colecao no admin

**Feature:** F06
**Wave:** 1
**Type:** frontend
**Depends on:** F06-T01
**Status:** planned

## User Story

As the store owner, I want to toggle a collection's visibility from the admin panel, so that I can temporarily hide collections from the public site.

## Objective

Adicionar botao "Ocultar" / "Exibir" na UI do admin para cada colecao, com alerta de confirmacao.

## Dev Notes

- File: `admin/public/index.html`
- Na funcao que renderiza cards de colecao (por volta da linha 520-590), adicionar botao:
  - Se `c.hidden`: botao "Exibir" com icone olho (btn-outline + verde)
  - Se nao `c.hidden`: botao "Ocultar" com icone olho-riscado (btn-outline + amarelo/warning)
- Badge visual no card: se oculta, mostrar badge "Oculta" em amarelo
- Ao clicar, mostrar confirmDialog:
  - **Ocultar**: "Ocultar colecao X?" + "A colecao sera removida do site publico, mas pode ser reexibida a qualquer momento."
  - **Exibir**: "Exibir colecao X?" + "A colecao voltara a aparecer no site publico."
- Funcao JS:
  ```javascript
  async function toggleCollectionVisibility(slug) {
    const c = collections.find((x) => x.slug === slug);
    const newHidden = !c.hidden;
    const action = newHidden ? "Ocultar" : "Exibir";
    const msg = newHidden
      ? "A colecao sera removida do site publico, mas pode ser reexibida a qualquer momento."
      : "A colecao voltara a aparecer no site publico.";
    confirmDialog(
      `${action} "${c.name}"?`,
      msg,
      async () => {
        await fetch(`/api/collections/${slug}`, {
          method: "PUT",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ hidden: newHidden }),
        });
        toast(`Colecao ${newHidden ? "ocultada" : "exibida"}!`);
        await loadCollections();
      },
      { confirmText: action, confirmClass: newHidden ? "btn-outline" : "btn-green" },
    );
  }
  ```
