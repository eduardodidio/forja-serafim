# Task F06-T03 — Melhorar alerta de exclusao de colecao

**Feature:** F06
**Wave:** 1
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As the store owner, I want a clear warning when deleting a collection, so that I don't accidentally lose data permanently.

## Objective

Melhorar o dialog de confirmacao ao excluir colecao para tornar claro que a acao e irreversivel.

## Dev Notes

- File: `admin/public/index.html`
- Funcao `confirmDeleteCollection` (linha 784):
  - Mudar titulo para: `Excluir "${c.name}" permanentemente?`
  - Mudar mensagem para incluir:
    - Icone de alerta vermelho (SVG triangle-exclamation)
    - Texto: "ATENCAO: Esta acao e IRREVERSIVEL. A colecao, suas imagens e dados serao excluidos permanentemente. Se voce quer apenas remover temporariamente do site, use a opcao 'Ocultar' em vez disso."
  - Mudar botao de "Remover" para "Excluir permanentemente"
  - Adicionar classe extra ao botao: vermelho mais intenso
- Considerar adicionar delay de 3 segundos no botao de confirmar (para evitar clique acidental):
  ```javascript
  // Desabilitar botao por 3 segundos
  const btn = document.getElementById('confirm-btn');
  btn.disabled = true;
  btn.textContent = 'Aguarde (3s)...';
  setTimeout(() => { btn.disabled = false; btn.textContent = 'Excluir permanentemente'; }, 3000);
  ```
