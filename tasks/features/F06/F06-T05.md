# Task F06-T05 — Filtrar colecoes ocultas no site publico

**Feature:** F06
**Wave:** 2
**Type:** frontend
**Depends on:** F06-T01
**Status:** planned

## User Story

As a visitor, I should not see hidden collections on the public site, so that only active collections are displayed.

## Objective

Filtrar colecoes com `hidden: true` do site publico em todos os pontos onde sao listadas.

## Dev Notes

- File: `src/lib/store-data.ts`
- Adicionar export filtrado:
  ```typescript
  export const visibleCollections: Collection[] = collectionsData.filter(c => c.hidden !== true);
  ```
- Manter `collections` (todas) para uso interno se necessario
- Atualizar imports nos seguintes arquivos:
  1. `src/routes/index.tsx` — linha 17: trocar `collections` por `visibleCollections`
  2. `src/routes/colecoes.index.tsx` — linha 4: trocar `collections` por `visibleCollections`
- **NAO** filtrar em `colecoes.$slug.tsx` (`getCollection`) — se alguem tiver o link direto, pode ver (ou redirecionar para 404 se preferir; discutir com usuario)
- O sitemap (se existir) tambem deve excluir colecoes ocultas

## Testing

- Manual: acessar URL direta da colecao oculta — deve funcionar (ou 404, a definir)
