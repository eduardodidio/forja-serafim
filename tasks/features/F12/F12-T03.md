# F12-T03 — Testimonial text limit + input validation hardening

**Status:** done
**Wave:** 2
**Depends on:** F12-T01

## User Story

Como administrador, quero que inputs de texto tenham limites razoaveis e que
erros de validacao sejam claros, para evitar dados corrompidos ou bloated.

## Dev Notes

### 1. Limite de tamanho no campo text de testimonial

`admin/src/server.ts` linha ~512: `body.text` aceito sem limite.
Adicionar validacao:

```ts
if (body.text.length > 500) {
  return json({ error: "Texto do depoimento deve ter no maximo 500 caracteres." }, 400, req);
}
if (body.name.length > 100) {
  return json({ error: "Nome deve ter no maximo 100 caracteres." }, 400, req);
}
```

### 2. Limite de tamanho no campo deck do testimonial

`body.deck` tambem aceito sem limite. Adicionar:

```ts
if (body.deck && body.deck.length > 100) {
  return json({ error: "Nome do deck deve ter no maximo 100 caracteres." }, 400, req);
}
```

### 3. Validacao de tamanho em outros campos de collection

Verificar se `name`, `description`, URLs de collection tem limites razoaveis nos
endpoints POST/PUT de `/api/collections`.
