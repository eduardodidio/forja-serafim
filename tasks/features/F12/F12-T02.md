# F12-T02 — PWA manifest link + icon sizes fix

**Status:** done
**Wave:** 1
**Depends on:** F12-T01

## User Story

Como usuario, quero que o site seja instalavel como PWA desde o primeiro carregamento,
sem depender de JavaScript para descobrir o manifest.

## Dev Notes

### 1. Adicionar `<link rel="manifest">` em `index.html`

Atualmente o link so existe em `__root.tsx` via TanStack Router `head()`, que so
roda apos hydrate do React. Lighthouse e crawlers PWA checam o HTML inicial.

Adicionar no `<head>` do `index.html`:

```html
<link rel="manifest" href="/manifest.json" />
```

### 2. Corrigir icons no `public/manifest.json`

Atualmente ambos os icons apontam para `/favicon.png` mas declaram sizes diferentes
(192x192 e 512x512). O arquivo real tem so um tamanho.

**Opcao A (simples):** Declarar o tamanho real do arquivo e remover o entry duplicado:

```json
"icons": [
  {
    "src": "/favicon.png",
    "sizes": "512x512",
    "type": "image/png",
    "purpose": "any maskable"
  }
]
```

**Opcao B (ideal):** Gerar favicon-192.png (192x192) a partir do favicon.png e manter
ambos os entries com tamanhos corretos.

Verificar o tamanho real do `favicon.png` antes de decidir.

### 3. Remover entry redundante do `__root.tsx` (opcional)

Se `index.html` ja tem o manifest link, o entry em `__root.tsx` head() linha 80
eh redundante (duplica o tag). Remover para evitar tag duplicado no DOM.
