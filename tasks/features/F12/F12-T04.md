### 1. Atualizar CLAUDE.md — stack real

O CLAUDE.md diz:

> Stack: **TanStack Start + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui**

- React 19
- TypeScript
- Tailwind CSS v4

Tambem atualizar a descricao na secao Architecture:

> ~~TanStack Start (Vite + React 19 + SSR) com roteamento file-based.~~
> Vite + React 19 com TanStack Router (file-based routing, client-side SPA).

### 2. eslint no-unused-vars → warn

Em `eslint.config.js` linha ~36:

```js
"@typescript-eslint/no-unused-vars": "off",
```

Mudar para:

```js
"@typescript-eslint/no-unused-vars": ["warn", {
  argsIgnorePattern: "^_",
  varsIgnorePattern: "^_"
}],
```

Isso permite prefixar variaveis ignoradas com `_` (padrao comum) mas alerta
sobre variaveis realmente nao usadas.

### 3. Rodar lint e corrigir warnings

Apos mudar a regra, rodar `bun run lint` e corrigir ou prefixar com `_`
qualquer variavel que gere warning.
