**Wave:** 0

## User Story

As the admin server, I need a reliable way to auto-commit and push data changes to git after every mutation, so that changes survive Render redeploys without manual intervention.

### Implementation details:

1. **Serial queue**: Use a promise chain pattern — each `gitPersist()` call chains onto the previous one. This ensures no concurrent `git add/commit/push` operations (Saruman condition #1).

```typescript
let queue: Promise<PersistResult> = Promise.resolve({ committed: false, pushed: false });

export function gitPersist(description: string): Promise<PersistResult> {
  queue = queue.then(() => doGitPersist(description)).catch(/* ... */);
  return queue;
}
```

2. **doGitPersist(description)**:
   - Set state to `dirty`
   - `git add` the data paths:
     - `src/data/collections.json`
     - `src/data/testimonials.json`
     - `src/data/settings.json`
     - `public/images/covers/`
     - `public/images/decks/`
     - `public/manuals/`
   - `git diff --cached --name-only` — if empty, state = `clean`, return `{ committed: false, pushed: false }`
   - `git commit -m "Auto-save: <description>"`
   - Set state to `pushing`
   - Push using `GITHUB_TOKEN` (same logic as current publish endpoint, lines 674-697 of server.ts)
   - On success: state = `clean`, return `{ committed: true, pushed: true }`
   - On push failure: state = `error`, store error message, return `{ committed: true, pushed: false, error }`

3. **Git config**: Reuse the same git user config from server.ts (lines 788-798)

4. **Import `PROJECT_ROOT`** from `./paths.ts`

5. **Use `execSync`** with `{ cwd: PROJECT_ROOT, encoding: "utf-8", stdio: "pipe" }` — same pattern as publish

6. **Handle detached HEAD**: Same checkout-main logic from publish (lines 647-658)
