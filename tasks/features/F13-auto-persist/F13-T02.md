# F13-T02: Integrate gitPersist into all 12 mutation endpoints

**Wave:** 1
**Status:** planned
**Depends on:** F13-T01

## User Story

As a site admin, after I make any change (upload image, edit collection, add testimonial, etc.), the change is automatically saved to git so I never lose data.

## Dev Notes

### File: `admin/src/server.ts`

Import `gitPersist` from `./lib/git-persist.js` at the top.

After each mutation endpoint returns its JSON response successfully, fire `gitPersist()` **without awaiting** (fire-and-forget). The HTTP response returns immediately; the git operation happens in the background.

### Pattern:

```typescript
// Before (example: create collection)
writeJson(COLLECTIONS_JSON, collections);
return json(newCol, 201, req);

// After
writeJson(COLLECTIONS_JSON, collections);
gitPersist(`Criar colecao: ${newCol.name}`);
return json(newCol, 201, req);
```

### All 12 endpoints to modify:

| #   | Endpoint                                                 | Description for commit                                |
| --- | -------------------------------------------------------- | ----------------------------------------------------- |
| 1   | `POST /api/collections` (line ~302)                      | `Criar colecao: ${name}`                              |
| 2   | `PUT /api/collections/:slug` (line ~339)                 | `Editar colecao: ${slug}`                             |
| 3   | `DELETE /api/collections/:slug` (line ~346)              | `Remover colecao: ${slug}`                            |
| 4   | `POST /api/collections/:slug/cover` (line ~367)          | `Atualizar capa: ${slug}`                             |
| 5   | `POST /api/collections/:slug/manual` (line ~393)         | `Upload manual: ${slug}`                              |
| 6   | `PUT /api/collections/:slug/images/reorder` (line ~422)  | `Reordenar imagens: ${slug}`                          |
| 7   | `DELETE /api/collections/:slug/images/:file` (line ~456) | `Remover imagem: ${slug}/${filename}`                 |
| 8   | `POST /api/collections/:slug/images` (line ~531)         | `Upload amostras: ${slug} (${processed.length} imgs)` |
| 9   | `POST /api/testimonials` (line ~554)                     | `Adicionar depoimento: ${name}`                       |
| 10  | `PUT /api/testimonials/:idx` (line ~577)                 | `Editar depoimento #${idx}`                           |
| 11  | `DELETE /api/testimonials/:idx` (line ~584)              | `Remover depoimento #${idx}`                          |
| 12  | `PUT /api/settings` (line ~598)                          | `Atualizar configuracoes`                             |

### Important:

- `gitPersist()` is called but NOT awaited — response returns immediately
- The serial queue inside gitPersist handles ordering
- For image uploads (#4, #5, #8): gitPersist stages the binary files too (covers/, decks/, manuals/ dirs)
