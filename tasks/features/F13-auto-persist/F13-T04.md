# F13-T04: Add dirty-state banner UI to admin panel

**Wave:** 2
**Status:** planned
**Depends on:** F13-T03

## User Story

As a site admin, I need a clear visual indicator showing whether my changes are saved to git, so I know if data is at risk of being lost on a server restart.

### File: `admin/public/index.html`

#### 2. Banner states (CSS classes):

| State     | Background                                              | Icon           | Text                                                       | Retry button |
| --------- | ------------------------------------------------------- | -------------- | ---------------------------------------------------------- | ------------ |
| `clean`   | hidden                                                  | -              | -                                                          | hidden       |
| `dirty`   | `bg-yellow-900/30 border-yellow-700/40 text-yellow-300` | spinning sync  | "Salvando alteracoes..."                                   | hidden       |
| `pushing` | `bg-blue-900/30 border-blue-700/40 text-blue-300`       | spinning arrow | "Enviando para o GitHub..."                                | hidden       |
| `error`   | `bg-red-900/30 border-red-700/40 text-red-300`          | error icon     | "Erro ao salvar no GitHub. Alteracoes podem ser perdidas." | visible      |

#### 3. JavaScript

```javascript
let persistState = "clean";

async function checkPersistStatus() {
  try {
    const res = await fetch(`${API}/api/persist-status`);
    if (!res.ok) return;
    const { state, error } = await res.json();
    updatePersistBanner(state, error);
  } catch {
    /* ignore network errors */
  }
}

function updatePersistBanner(state, error) {
  persistState = state;
  const banner = document.getElementById("persist-banner");
  const icon = document.getElementById("persist-icon");
  const text = document.getElementById("persist-text");
  const retry = document.getElementById("persist-retry");

  if (state === "clean") {
    banner.classList.add("hidden");
    return;
  }

  banner.classList.remove("hidden");
  // ... set classes and text based on state table above
  retry.classList.toggle("hidden", state !== "error");
}

async function retryPersist() {
  await fetch(`${API}/api/persist-retry`, { method: "POST" });
  checkPersistStatus();
}
```

#### 4. Polling

- Poll `/api/persist-status` every **3 seconds** while state is NOT `clean`
- Poll every **15 seconds** when state is `clean` (background check)
- Also check immediately after any mutation response

#### 5. Saruman condition #3

Banner with `error` state is **non-dismissable** — no close button. It stays until push succeeds or user clicks retry.

#### 6. Adjust tab bar sticky position

The tab bar at line ~609 has `sticky top-[65px]`. When banner is visible, adjust to `top-[97px]` (65px header + 32px banner). Use JS to toggle.
