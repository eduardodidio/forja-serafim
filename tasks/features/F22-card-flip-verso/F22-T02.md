# F22-T02 — Adicionar flip state e animacao CSS ao Lightbox

**Status:** done
**Wave:** 1

## User Story

Como visitante inspecionando um card no lightbox, quero clicar no card para ve-lo
virar com uma animacao suave de flip horizontal, revelando o verso da carta.
Clicar novamente volta para a frente. A animacao deve ser organica (~600ms),
como virar uma carta de verdade.

## Dev Notes

### Arquivo: `src/components/lightbox.tsx`

#### 1. State de flip

Adicionar state `flipped` que reseta quando o index muda:

```ts
const [flipped, setFlipped] = useState(false);

// Reset flip quando trocar de card (prev/next)
useEffect(() => {
  setFlipped(false);
}, [index]);
```

#### 2. Handler de clique no card

O div wrapper do card (linha ~108-126) ja tem `onClick={(e) => e.stopPropagation()}`.
Trocar para tambem toggle o flip:

```ts
onClick={(e) => {
  e.stopPropagation();
  setFlipped((f) => !f);
}}
```

#### 3. Estrutura HTML do flip

Substituir o bloco do card (atualmente `<Card3DTilt>` com `<img>`) por uma
estrutura de flip container com duas faces:

```tsx
<div
  key={index}
  onClick={(e) => {
    e.stopPropagation();
    setFlipped((f) => !f);
  }}
  onContextMenu={(e) => e.preventDefault()}
  style={{ animation: "fade-in 0.2s ease-out", perspective: "1200px" }}
  className="cursor-pointer"
>
  <Card3DTilt tiltMaxAngle={18} scale={1.08} className="inline-block">
    <div
      style={{
        transformStyle: "preserve-3d",
        transition: "transform 0.6s cubic-bezier(0.4, 0.0, 0.2, 1)",
        transform: flipped ? "rotateY(180deg)" : "rotateY(0deg)",
      }}
    >
      {/* Frente */}
      <img
        src={images[index]}
        alt={`${alt} ${index + 1}`}
        className="max-h-[90vh] max-w-[90vw] rounded-lg object-contain"
        style={{
          userSelect: "none",
          pointerEvents: "none",
          backfaceVisibility: "hidden",
        }}
        draggable={false}
      />
      {/* Verso */}
      <img
        src={CARD_BACK_IMAGE}
        alt="Verso da carta"
        className="absolute inset-0 max-h-[90vh] max-w-[90vw] rounded-lg object-contain"
        style={{
          userSelect: "none",
          pointerEvents: "none",
          backfaceVisibility: "hidden",
          transform: "rotateY(180deg)",
        }}
        draggable={false}
      />
    </div>
  </Card3DTilt>
</div>
```

#### 4. Detalhes da animacao

- **Duracao**: `0.6s` (600ms) — organico, nao instantaneo
- **Easing**: `cubic-bezier(0.4, 0.0, 0.2, 1)` — ease-out material, suave
- **Transform**: `rotateY(180deg)` — flip horizontal
- **Perspective**: `1200px` no container pai — profundidade 3D realista
- **backfaceVisibility: hidden** em ambas as faces — evita ver a imagem invertida

#### 5. Posicionamento do verso

O verso precisa de `position: relative` no container e `position: absolute` +
`inset: 0` no verso para sobrepor a frente. Garantir que ambas as imagens
tenham as mesmas dimensoes max (max-h/max-w).

O container `div` que envolve as duas imagens precisa de `position: relative`
para o absolute do verso funcionar.

#### 6. Indicador visual (opcional mas recomendado)

Adicionar uma dica sutil de que o card eh clicavel para virar. Pode ser um
pequeno icone de flip (RotateCw do lucide) no canto inferior direito do card
dentro do lightbox, com opacity baixa:

```tsx
<div className="absolute bottom-3 right-3 rounded-full bg-black/40 p-1.5 text-white/50">
  <RotateCw className="size-4" />
</div>
```
