# F22-T01 — Mover verso.jpeg para public/ e preload da imagem

**Status:** done
**Wave:** 1

## User Story

Como visitante, quero que o verso da carta carregue instantaneamente quando eu
clicar para virar o card no lightbox, sem flash de imagem faltando.

## Dev Notes

### 1. Mover asset

- Copiar `docs/verso.jpeg` para `public/images/verso.jpg`
- Se o arquivo nao estiver em `docs/`, pedir ao usuario para confirmar o path
- Garantir que o formato eh JPEG valido

### 2. Constante de path

No arquivo `src/components/lightbox.tsx` (ou em um novo modulo se preferir),
definir uma constante:

```ts
const CARD_BACK_IMAGE = "/images/verso.jpg";
```

### 3. Preload no lightbox

Quando o lightbox abrir (`isOpen` virar true), fazer preload do verso:

```ts
useEffect(() => {
  if (!isOpen) return;
  const img = new Image();
  img.src = CARD_BACK_IMAGE;
}, [isOpen]);
```

Isso garante que a imagem ja esta em cache quando o usuario clicar para virar.
