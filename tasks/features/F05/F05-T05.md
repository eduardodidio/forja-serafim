**Type:** frontend

## User Story

As a visitor, I want to see 6 sample cards per collection in a 3x2 grid, so that I get a better preview of the deck quality.

## Objective

Adicionar uma 6a imagem de amostra em cada colecao. Os ZIPs originais dos decks nao estao no repo, entao precisamos processar uma imagem adicional de cada deck manualmente ou via admin.
