# Task F05-T04 — Tornar watermark mais evidente

**Feature:** F05
**Wave:** 1
**Type:** backend
**Depends on:** (none)
**Status:** planned

## User Story

As the store owner, I want the watermark "Forja Serafim" to be more visible on sample images, so that my brand is clearly identified and images are better protected.

## Objective

Aumentar visibilidade da watermark no processador de imagens do admin. O texto "Forja Serafim" ja esta correto, mas precisa ser mais legivel.

## Dev Notes

- File: `admin/src/lib/image-processor.ts`
- Mudancas:
  1. `fill-opacity` de `0.25` para `0.40` (linha 15)
  2. Font-size factor de `0.06` para `0.08` (linha 8: `Math.max(24, Math.round(width * 0.08))`)
  3. Adicionar text-shadow/stroke SVG para melhor contraste:
     ```
     stroke="black" stroke-width="1" stroke-opacity="0.3"
     ```
  4. Considerar aumentar `lines` de 5 para 6 para melhor cobertura
- WATERMARK_TEXT ja esta "Forja Serafim" (correto)
- NOTA: imagens existentes NAO serao reprocessadas automaticamente. Apenas novas imagens terao a watermark atualizada. Para reprocessar, Anderson precisa re-upload via admin.
