# F24-T01 — Add id anchors to existing homepage sections + smooth scroll CSS

**Status:** planned
**Wave:** 1
**Depends on:** —

## User Story

As a visitor, I want clicking a nav link to smoothly scroll to the corresponding section on the homepage.

## Dev Notes

### 1. Add `scroll-behavior: smooth` to the HTML root

In `src/index.css` or the Tailwind base layer, add:
```css
html {
  scroll-behavior: smooth;
}
```

### 2. Add `id` attributes to existing sections in `src/routes/index.tsx`

- Hero section: add `id="home"`
- Collections section (the one with "Universos em papel"): add `id="colecoes"`
- Pricing section already has `id="valores"`
- Shipping section already has `id="frete"`

### 3. Add scroll-margin-top

Since the header is sticky, anchored sections need offset. Add to CSS:
```css
[id] {
  scroll-margin-top: 5rem;
}
```

## Files to modify

- **Modify:** `src/routes/index.tsx` — add `id="home"` and `id="colecoes"` to sections
- **Modify:** `src/index.css` (or equivalent Tailwind CSS file) — smooth scroll + scroll-margin
