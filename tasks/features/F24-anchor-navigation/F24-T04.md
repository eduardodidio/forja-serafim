# F24-T04 — Convert header to all-anchor navigation

**Status:** planned
**Wave:** 1
**Depends on:** —

## User Story

As a visitor, I want all header nav links to scroll to sections on the homepage instead of navigating to separate pages.

## Dev Notes

### 1. Replace the dual links/anchorLinks system in `src/components/site-header.tsx`

Current state: `links` array (TanStack Router `Link`) + `anchorLinks` array (`<a>` tags).

Replace with a single anchor links array:

```ts
const navLinks = [
  { href: "/#home", label: "Home" },
  { href: "/#colecoes", label: "Colecoes" },
  { href: "/#sobre", label: "Sobre" },
  { href: "/#valores", label: "Valores" },
  { href: "/#contato", label: "Contato" },
];
```

### 2. Replace `<Link>` with `<a>` in both desktop and mobile nav

Desktop nav:
```tsx
{navLinks.map((l) => (
  <a
    key={l.href}
    href={l.href}
    className="text-sm text-muted-foreground transition-colors hover:text-gold"
  >
    {l.label}
  </a>
))}
```

Mobile nav (same pattern, with `onClick={() => setOpen(false)}`).

### 3. Remove TanStack Router `Link` import if no longer used

Check if `Link` is still needed (the logo link to "/" can become `<a href="/">`).

### 4. Active state (optional)

Can be dropped since anchor links don't have router active state. If needed later, use IntersectionObserver — but skip for now to keep it simple.
