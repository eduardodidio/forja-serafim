# F02-T05: Configurações — layout melhorado

**Wave:** 2 | **Type:** frontend | **Status:** done | **Depends on:** T01

## User Story

Como Anderson, quero que a tela de configurações seja clara e organizada para que
eu possa atualizar dados de contato facilmente.

## Dev Notes

Redesenhar o painel de configurações:

### Layout

- Card maior, centralizado, com padding generoso
- Título da seção "Contato" com ícone de WhatsApp
- Input do WhatsApp com ícone de telefone à esquerda (input group)
- Validação visual: borda verde se formato válido, vermelha se inválido
- Texto de ajuda mais visível com exemplo formatado
- Botão "Salvar" com ícone de check, estado disabled se nada mudou

### Feedback

- Após salvar: toast de sucesso + flash sutil no card
- Se erro: toast de erro com mensagem clara

### Futuro-proof

- Estrutura preparada para novos campos de configuração
  (usar seções com dividers, como "Contato", "Aparência", etc.)
  — mas só implementar a seção Contato por enquanto

## Files affected

- `admin/public/index.html` — rewrite seção settings

## Acceptance criteria

- [ ] Card com layout limpo e ícone de WhatsApp
- [ ] Input com ícone decorativo
- [ ] Texto de ajuda visível
- [ ] Botão salvar funcional
- [ ] Valor carrega corretamente do settings.json

## Testing
