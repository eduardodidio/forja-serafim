# F02-T06: Publicação redesenhada e polish final

**Wave:** 3 | **Type:** frontend | **Status:** done | **Depends on:** T01, T02, T03, T04, T05

## User Story

Como Anderson, quero que o processo de publicação tenha feedback visual claro passo
a passo para que eu saiba exatamente o que está acontecendo e se deu certo.

## Dev Notes

### Botão Publicar
- Mais proeminente no header: gradiente verde, ícone de foguete
- Estado loading: spinner animado + "Publicando..." com pulso
- Estado desabilitado: cinza, cursor not-allowed

### Modal de Progresso de Publicação
- Em vez de esperar tudo e mostrar resultado, mostrar steps em tempo real:
  - Step 1: "Compilando site..." (ícone spinner → check)
  - Step 2: "Salvando alterações..." (ícone spinner → check)
  - Step 3: "Enviando para GitHub..." (ícone spinner → check)
  - Step 4: "Disparando deploy no Render..." (ícone spinner → check)
- Cada step muda de spinner para check verde conforme conclui
- Se erro: step fica vermelho com ícone X + mensagem
- Botão "Fechar" só aparece quando todos os steps concluírem

### Confirmação
- Substituir confirm() nativo por modal customizado estilizado:
  "Publicar todas as alterações?" com ícone de warning/info,
  "Isso vai atualizar o site online", botões "Cancelar" e "Publicar"

### Polish Final
- Verificar consistência visual em todas as telas
- Garantir que todos os botões têm hover states
- Garantir que todos os inputs têm focus states com borda dourada
- Verificar que não há flash de conteúdo no carregamento inicial
- Adicionar fade-in sutil ao carregar listas

## Files affected

- `admin/public/index.html` — rewrite `publish()`, confirm customizado, polish global

- [ ] Botão publicar com visual premium e estados (normal, loading, disabled)

- [ ] Funcionalidade de publicação preservada (build + commit + push + deploy hook)

## Testing

- Clicar publicar: verificar modal de confirmação customizado
- Confirmar: verificar modal de progresso com steps
