# F02-T04: Depoimentos — cards e formulários redesenhados

**Wave:** 2 | **Type:** frontend | **Status:** done | **Depends on:** T01

## User Story

Como Anderson, quero que a seção de depoimentos seja visualmente agradável e fácil
de gerenciar para que eu possa adicionar feedback de clientes com confiança.

## Dev Notes

Redesenhar `renderTestimonials()` e modais:

### Cards de Depoimento
- Aspas decorativas grandes (") como elemento visual
- Avatar com iniciais em círculo dourado (manter, mas maior e mais bonito)
- Nome em destaque, deck associado como badge colorido
- Texto do depoimento em itálico com fonte levemente maior
- Botões Editar/Remover alinhados, com ícones
- Hover sutil no card (border glow)

### Empty State
- Ícone de aspas/chat + texto "Nenhum depoimento ainda"
- Botão "Adicionar primeiro depoimento"

### Modal de Novo/Editar Depoimento
- Layout limpo com campos bem espaçados
- Textarea do depoimento com contador de caracteres (opcional, nice-to-have)
- Select de deck com visual melhorado (custom styled)
- Preview do card antes de salvar (nice-to-have)

### Confirmação de Exclusão
- Substituir confirm() nativo por modal customizado bonito
  com ícone de warning, texto claro, botões "Cancelar" e "Remover" (vermelho)

## Files affected

- `admin/public/index.html` — rewrite `renderTestimonials()`, `openAddTestimonial()`,
  `openEditTestimonial()`, `deleteTestimonial()` com confirm customizado

## Acceptance criteria

- [ ] Cards de depoimento com aspas decorativas e visual premium
- [ ] Empty state quando não há depoimentos
- [ ] Modal de criação/edição limpo e claro
- [ ] Confirmação de exclusão via modal customizado (não confirm nativo)
- [ ] Dados preservados identicos

## Testing

- Verificar com 0 depoimentos (empty state)
- Adicionar depoimento (modal + toast)
- Editar depoimento existente (campos preenchidos)
- Remover depoimento (modal de confirmação customizado)
