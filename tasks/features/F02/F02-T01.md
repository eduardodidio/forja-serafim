# F02-T01: Layout, design system e header/nav redesign

**Wave:** 0 | **Type:** frontend | **Status:** done | **Depends on:** —

## User Story

Como Anderson, quero que o painel admin tenha uma aparência profissional e premium
para que eu me sinta confiante usando a ferramenta para gerenciar meu negócio.

## Dev Notes

Reescrever a estrutura base do `admin/public/index.html`:

### Design System
- Paleta: fundo escuro gradiente (deeper → surface), dourado (#d4a853) como accent,
  bordas sutis com glow dourado nos elementos ativos
- Tipografia: Inter (Google Fonts) ou system-ui com hierarquia clara (headings bold,
  body regular, labels small caps)
- Bordas e sombras: rounded-2xl nos cards, shadow com tint dourado sutil,
  border-gradient nos cards em hover
- Transitions: todas as interações com transition suave (200-300ms)

### Header
- Logo "A Casa do Serafim" maior com ícone decorativo (usar Unicode/emoji de coroa ou estrela)
- Subtítulo "Painel Administrativo" com badge estilizado
- Botão "Publicar" mais proeminente, com ícone de rocket/upload
- Link "Ver site" com ícone externo

### Navegação (Tabs)
- Tabs com ícones (cards para Coleções, chat para Depoimentos, gear para Config)
- Tab ativo com underline dourado animado + background sutil
- Contadores em badges (ex: "Coleções (3)", "Depoimentos (5)")

### Utilitários globais
- Loading skeleton/spinner global durante fetches
- Toast redesenhado: com ícone (check/x), animação slide-in, auto-dismiss com barra de progresso
- Modal redesenhado: com backdrop blur, animação scale-in, botão X no canto
