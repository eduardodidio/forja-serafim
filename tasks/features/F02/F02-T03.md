# F02-T03: Modais de coleção e uploads redesenhados

**Wave:** 1 | **Type:** frontend | **Status:** done | **Depends on:** T01

## User Story

Como Anderson, quero que os formulários de criação/edição de coleção sejam claros
e os uploads tenham feedback visual para que eu saiba o que está acontecendo.

## Dev Notes

Redesenhar modais de coleção e experiência de upload:

### Modal de Nova Coleção / Editar
- Formulário em seções visuais com dividers:
  - Seção "Informações" (nome, descrição, quantidade)
  - Seção "Links" (DeckCheck, Moxfield) com ícones nos inputs
  - Seção "Capa" (upload) — apenas no modal de criação
- Inputs com labels flutuantes ou labels bold acima
- Campos obrigatórios com asterisco dourado
- Preview da imagem de capa selecionada antes do upload
- Botões no footer com espaçamento adequado

### Upload de Cover (inline no card)
- Drag-and-drop zone estilizada (ou click)
- Preview inline da imagem antes de confirmar
- Progress indicator durante upload (spinner ou barra)
- Feedback visual de sucesso (ícone check + flash no card)

### Upload de Imagens do Deck
- Drag-and-drop zone com texto "Arraste imagens aqui"
- Preview grid das imagens selecionadas antes do upload
- Counter: "X imagens selecionadas"
- Progress: "Processando X de Y..."
- Feedback ao concluir

### Upload de Manual PDF
- Estilo similar, com ícone de PDF
- Nome do arquivo selecionado visível antes do upload

## Files affected

- `admin/public/index.html` — rewrite `openAddCollection()`, `openEditCollection()`,
  upload handlers com feedback visual

## Acceptance criteria

- [ ] Modal de criação com seções visuais e preview de capa
- [ ] Modal de edição preserva todos os campos
- [ ] Uploads com feedback visual (spinner/progress)
- [ ] Preview de imagem antes de upload de capa
- [ ] Counter de imagens no upload de deck
- [ ] Todas as APIs chamadas corretamente (sem mudança funcional)

## Testing

- Criar nova coleção com capa (verificar preview + upload)
- Editar coleção existente (verificar que campos preenchem corretamente)
- Upload de cover inline (verificar feedback + imagem atualiza)
- Upload múltiplo de imagens de deck (verificar counter + progress)
- Upload de PDF manual (verificar feedback)
