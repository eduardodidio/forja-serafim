# F02-T02: Cards de coleções — layout visual rico

**Wave:** 1 | **Type:** frontend | **Status:** done | **Depends on:** T01

## User Story

Como Anderson, quero ver minhas coleções em cards bonitos e informativos para que
eu tenha uma visão clara do que já está cadastrado e do que falta.

## Dev Notes

Redesenhar `renderCollections()` com cards visuais ricos:

### Card de Coleção

- Layout: cover image como banner no topo do card (aspect-ratio 16:9 ou 3:1),
  não mais thumbnail pequeno no canto
- Nome da coleção em destaque (text-xl, text-gold, font-bold)
- Descrição com truncate elegante (line-clamp-2)
- Stats em row: "XX cartas" com ícone, contagem de amostras com ícone
- Status badges coloridos para DeckCheck, Moxfield, Manual:
  - Verde com ícone check se preenchido
  - Cinza pontilhado se não preenchido (call-to-action visual)
- Botões de ação: ícones + texto, agrupados com separador visual
  - "Editar" (ícone pencil), "Remover" (ícone trash, vermelho)
- Galeria de sample images: grid ou carrossel horizontal com thumbnails
  maiores (h-28 w-20), com borda arredondada e hover zoom sutil

### Empty State

- Quando não há coleções: ilustração/ícone grande + texto convidativo
  - botão "Criar primeira coleção" proeminente

### Botão "Nova Coleção"

- Mais visível, com ícone "+" e texto
