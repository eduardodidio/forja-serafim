## User Story

As the store owner, I want smooth transitions and consistent hover effects throughout the admin panel, so the experience feels premium everywhere.

## Objective

Revisao final de polish em todo o admin: transicoes, estados de hover, e ajustes responsivos.

## Dev Notes

### Transicoes globais

- File: `admin/public/index.html`
- Toast notifications: fade-in slide-right
- Tabs: transicao de underline suave (transform, nao width)
- Cards da lista: hover com elevacao sutil (translateY(-2px), shadow increase)
- Botoes: transicao de 200ms em background, transform, shadow

### Hover states

- Verificar que TODOS os elementos interativos tem hover state
- Links: color transition gold → gold-soft
- Imagens (thumbnails): scale sutil (1.02) com overflow hidden

### Responsividade

- Modal: max-w-lg em mobile, padding ajustado
- Grid de samples: 2 colunas em mobile (grid-cols-2 sm:grid-cols-3)
- Tabs: scroll horizontal se necessario em telas pequenas
- Botoes de acao: stack vertical em mobile

### Acessibilidade basica

- Focus rings dourados em todos os inputs/botoes
- Tab navigation funcional nos modais
