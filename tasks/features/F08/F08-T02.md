# Task F08-T02 — Modal de criacao premium

**Feature:** F08
**Wave:** 1
**Type:** frontend
**Depends on:** F08-T01
**Status:** planned

## User Story

As the store owner, I want the collection creation form to feel premium and polished, matching the quality of the main site.

## Objective

Redesenhar o modal de criacao de colecao com visual premium.

## Dev Notes

### Localizacao

- File: `admin/public/index.html` — funcao showAddModal e CSS relacionado

### Redesign

- Titulo do modal: font-display (Cinzel), text-gradient-gold
- Tabs de secao: underline dourada animada (ja existe .tab-btn, refinar)
- Campos de input: fundo transparente, borda sutil, borda dourada no focus com glow
- Labels: font-display em caixa alta, tracking wider, cor gold-soft
- Botao "Criar colecao": gradiente dourado, hover com scale sutil, sombra dourada
- Botao "Cancelar": ghost style, borda sutil
- Upload zone: borda dashed dourada, hover com background gold/5%, icone grande centralizado
- Separadores entre secoes: hairline dourado (como no site)

### Animacao do modal

- Entrada: fade-in + slide-up suave (300ms ease-out)
- Backdrop: fade-in com blur sutil

## Testing

- Manual: abrir modal de criacao, verificar visual premium
- Manual: verificar hover states em todos os elementos interativos
- Manual: verificar em mobile (responsivo)

## Acceptance criteria

- [ ] Modal de criacao visualmente premium
- [ ] Hover states funcionais em botoes, inputs, tabs
- [ ] Animacao de entrada suave
- [ ] Responsivo em mobile
