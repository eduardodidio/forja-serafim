# Task F08-T03 — Modal de edicao premium

**Feature:** F08
**Wave:** 1
**Type:** frontend
**Depends on:** F08-T01

## User Story

As the store owner, I want the collection editing form to feel as polished as the creation form, with a premium dark theme.

## Objective

Redesenhar o modal de edicao de colecao com o mesmo visual premium do modal de criacao.

## Dev Notes

- File: `admin/public/index.html` — funcao showEditModal e CSS relacionado

- Secoes colapsaveis ou tabs: Informacoes | Midia | Links
- Grid de sample images (ja implementado em F07-T02): garantir estilo premium
- Botoes de acao (Trocar capa, Manual PDF): estilo consistente com design system

### Upload zones
- Mesma melhoria de F08-T02 para todas as zones de upload
- Consistencia visual entre criacao e edicao
