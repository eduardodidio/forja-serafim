# Task F08-T01 — Design system: fontes e variaveis CSS do admin

**Feature:** F08
**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a developer, I want the admin panel to share the same design tokens as the main site, so that visual consistency is maintained.

## Objective

Alinhar o design system do admin (inline no HTML) com as variaveis CSS do site principal.

## Dev Notes

### Fontes
- File: `admin/public/index.html`
- Adicionar Google Fonts link para "Cinzel" (display) e "Jost" (body)
- Atualizar Tailwind config inline para usar essas fontes:
  ```js
  fontFamily: { display: ['Cinzel', 'Georgia', 'serif'], sans: ['Jost', 'sans-serif'] }
  ```

### Variaveis CSS
- Atualizar as cores customizadas do Tailwind CDN config para usar valores OKLch do site:
  - gold: `oklch(0.75 0.09 82)` (nao hex #d4a853)
  - surface: `oklch(0.21 0.012 265)`
  - deeper: `oklch(0.17 0.012 265)`
  - panel: `oklch(0.22 0.013 265)`
- Adicionar variaveis extras: gold-soft, crimson, gradientes

### Componentes base
- Atualizar `.btn` para usar gradiente dourado no hover
- Atualizar `.input` para borda dourada no focus
- Atualizar `.card` para usar surface-card pattern do site
- Atualizar `.modal-content` para borda com brilho dourado sutil
