# Task F09-T03 — Toggle de tema no admin

**Feature:** F09
**Wave:** 1
**Type:** frontend
**Depends on:** F09-T01
**Status:** planned

## User Story

As the store owner, I want a theme toggle in the admin panel so I can use it in light mode if preferred.

## Objective

Adicionar toggle de tema no admin panel com variaveis light e persistencia.

## Dev Notes

### Variaveis light no admin

- File: `admin/public/index.html`
- Adicionar bloco CSS com variaveis light (mesma paleta de F09-T01 adaptada)
- Atualizar Tailwind CDN config para suportar dark mode via class

### Toggle

- Adicionar botao Sun/Moon no top bar do admin (ao lado do email do usuario)
- Logica JS inline:
  ```js
  function toggleTheme() {
    document.documentElement.classList.toggle("dark");
    const theme = document.documentElement.classList.contains("dark") ? "dark" : "light";
    localStorage.setItem("admin-theme", theme);
  }
  ```
- Key separada: `admin-theme` (independente do site)

### Anti-FOUC

- Script no `<head>` do admin HTML:
  ```js
  if (localStorage.getItem("admin-theme") !== "light")
    document.documentElement.classList.add("dark");
  ```

### Componentes que precisam de ajuste

- `.btn`, `.input`, `.card`, `.modal-content` — verificar que usam variaveis CSS (nao cores hardcoded)
- Toast, badges, upload zones — verificar contraste em light
- Login page (`login.html`) — tambem precisa do toggle e variaveis light
