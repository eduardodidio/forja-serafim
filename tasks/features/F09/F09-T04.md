# Task F09-T04 — Testes visuais e ajustes de contraste

**Feature:** F09
**Wave:** 2
**Type:** frontend
**Depends on:** F09-T02, F09-T03
**Status:** planned

## User Story

As a user, I want both themes to be visually polished and accessible, with no readability issues.

## Objective

Revisar todas as paginas em light mode e corrigir problemas de contraste/visual.

## Dev Notes

### Paginas a verificar (site)
- Home (hero, colecoes grid, depoimentos, footer)
- Pagina de colecao (sample images grid, lightbox)
- 404

### Paginas a verificar (admin)
- Login
- Dashboard (lista de colecoes)
- Modais (criar, editar)
- Toasts e confirmacoes

### Checklist por pagina
- [ ] Texto legivel (contraste minimo WCAG AA — 4.5:1)
- [ ] Bordas visiveis
- [ ] Gradientes dourados funcionam em fundo claro
- [ ] Sombras visiveis mas nao exageradas
- [ ] Imagens (covers, samples) com borda/frame adequado
- [ ] Footer legivel
- [ ] Lightbox funcional em light mode

### Ajustes comuns esperados
- Shadow-soft: reduzir opacidade em light (fundo claro nao precisa de sombra tao forte)
- Gradient-veil: inverter para claro → transparente
- Art-frame hover: ajustar cor da borda e glow para light
- Text-gradient-gold: pode precisar de saturacao diferente em fundo claro

## Testing

- Manual: navegar por TODAS as paginas em light mode
- Manual: verificar contraste com devtools

## Acceptance criteria

- [ ] Todas as paginas legiveis em light mode
- [ ] Nenhum elemento "invisivel" ou com baixo contraste
- [ ] Gradientes e sombras adaptados
- [ ] Lightbox funcional em ambos os temas
