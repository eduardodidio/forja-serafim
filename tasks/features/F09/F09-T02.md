# Task F09-T02 — Toggle de tema no site header

**Feature:** F09
**Wave:** 1
**Type:** frontend
**Depends on:** F09-T01
**Status:** planned

## User Story

As a user, I want a theme toggle button in the site header so I can switch between dark and light modes.

## Objective

Adicionar botao de toggle de tema no header do site com persistencia em localStorage.

## Dev Notes

### Componente
- File: `src/components/site-header.tsx`
- Adicionar botao com icones Sun/Moon (Lucide Icons, ja disponivel no projeto)
- Posicionar ao lado dos links do header (antes do botao WhatsApp)

### Logica de tema
- File: `src/routes/__root.tsx` ou novo `src/lib/theme.ts`
- Funcao toggle: add/remove class "dark" no document.documentElement
- Salvar em localStorage key "theme" = "dark" | "light"
- Default: "dark" (se nao tem valor em localStorage)

### Script de inicializacao (anti-FOUC)
- No `__root.tsx`, adicionar script inline no `<head>`:
  ```html
  <script>
    (function(){
      var t = localStorage.getItem('theme');
      if (t !== 'light') document.documentElement.classList.add('dark');
    })();
  </script>
  ```
- Isso roda antes do React hidratar, prevenindo flash

### Animacao do toggle
- Icone: rotacao suave (180deg) na transicao
- Cor: dourada em ambos os temas

## Testing

- Manual: clicar toggle, verificar tema alterna
- Manual: recarregar pagina, verificar que tema persiste
- Manual: limpar localStorage, verificar que abre em dark

## Acceptance criteria

- [ ] Botao de toggle visivel no header
- [ ] Alterna entre dark e light corretamente
- [ ] Preferencia persiste em localStorage
- [ ] Sem flash ao recarregar (anti-FOUC)
- [ ] Icone animado na transicao
