**Feature:** F09
**Wave:** 0
**Type:** frontend
**Depends on:** (none)

## User Story

As a user, I want a light theme option so I can browse the site in well-lit environments comfortably.

## Objective

Definir variaveis CSS para o tema light, mantendo a identidade visual dourada.

## Dev Notes

### Variaveis light

- File: `src/styles.css`
- Mover variaveis atuais de `:root` para `.dark` (ou `:root.dark`)
- Criar `:root` (light por fallback) com cores claras:
  - --background: oklch(0.97 0.004 90) — creme/off-white
  - --foreground: oklch(0.2 0.012 265) — texto escuro
  - --surface: oklch(0.95 0.006 90) — superficie clara
  - --card: oklch(0.98 0.004 90) — card branco
  - --card-foreground: oklch(0.2 0.012 265) — texto card escuro
  - --gold: oklch(0.65 0.12 75) — dourado mais saturado para contraste em fundo claro
  - --gold-soft: oklch(0.75 0.09 82) — gold suave
  - --crimson: oklch(0.5 0.18 20) — crimson mais vibrante
  - --border: oklch(0.85 0.01 90) — borda sutil clara
  - --muted: oklch(0.92 0.006 90)
  - --muted-foreground: oklch(0.45 0.012 265)
  - Ajustar gradientes (gradient-gold, gradient-veil, shadows) para light

### Estrategia de dark como padrao

- O HTML carrega com class="dark" por padrao
- Script inline no `<head>` le localStorage antes do render:
  ```js
  if (localStorage.getItem("theme") !== "light") document.documentElement.classList.add("dark");
  ```
- Isso previne FOUC (flash of unstyled content)

### Tailwind dark variant

- Ja existe `@custom-variant dark (&:is(.dark *))` — perfeito, funciona com class strategy
