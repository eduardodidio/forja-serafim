# F15-T02 — Backend: endpoints de upload e delete de video

**Wave:** 1
**Status:** planned
**Depends on:** F15-T01

## User Story

Como administrador, preciso de endpoints na API para fazer upload e remover videos
de uma colecao, para que eu possa gerenciar videos demonstrativos sem depender do
desenvolvedor.

## Dev Notes

### 1. `POST /api/collections/:slug/video`

Localizar no server.ts, apos o bloco de upload de manual.

```
Fluxo:
1. Validar slug (isValidSlug)
2. req.formData() → file = formData.get("file")
3. Validar que file existe
4. Validar MIME type: apenas "video/mp4"
5. Validar tamanho: file.size <= 50 * 1024 * 1024 (50 MB)
6. Criar VIDEOS_DIR se nao existe (mkdirSync recursive)
7. Gravar arquivo em VIDEOS_DIR/<slug>.mp4
8. Atualizar collections.json: col.videoUrl = `/videos/decks/<slug>.mp4`
9. gitPersist(`Upload video: ${slug}`)
10. Retornar { path: `/videos/decks/<slug>.mp4` }
```

### 2. `DELETE /api/collections/:slug/video`

```
Fluxo:
1. Validar slug
2. Ler collections.json, encontrar colecao
3. Se videoUrl vazio → 404
4. Deletar arquivo fisico (unlinkSync) se existir
5. Limpar col.videoUrl = ""
6. writeJson + gitPersist(`Remover video: ${slug}`)
7. Retornar colecao atualizada
```

### 3. Import VIDEOS_DIR

Adicionar `VIDEOS_DIR` ao import de `./lib/paths.js`.

### 4. Rota match pattern

```ts
const videoMatch = path.match(/^\/api\/collections\/([^/]+)\/video$/);
```

Tratar POST e DELETE no mesmo bloco de match.

### 5. Servir videos estaticos

O MIME_TYPES ja tera `.mp4` (T01). Verificar que o static file serving
reconhece `/videos/decks/` como mutable asset para cache headers corretos.
Adicionar `path.startsWith("/videos/decks/")` ao check `isMutableAsset`.

## Acceptance Criteria

- [ ] POST /api/collections/:slug/video aceita upload MP4
- [ ] Rejeita arquivos nao-MP4 com erro 400
- [ ] Rejeita arquivos > 50 MB com erro 400
- [ ] Video salvo em public/videos/decks/<slug>.mp4
- [ ] collections.json atualizado com videoUrl correto
- [ ] gitPersist chamado apos upload
- [ ] DELETE /api/collections/:slug/video remove arquivo e limpa videoUrl
- [ ] DELETE retorna 404 se colecao nao tem video
- [ ] gitPersist chamado apos delete
- [ ] Videos servidos com MIME type correto e cache headers mutable

## Testing

- Upload de MP4 valido → 200, arquivo existe no disco, collections.json atualizado
- Upload de arquivo .avi → 400 com mensagem de erro
- Upload de MP4 > 50 MB → 400 com mensagem de erro
- Delete de video existente → 200, arquivo removido, videoUrl vazio
- Delete quando nao ha video → 404
- Slug invalido → 400
