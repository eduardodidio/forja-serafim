# F15-T03 — Admin UI: upload, preview e remocao de video

**Wave:** 2
**Status:** planned
**Depends on:** F15-T02

## User Story

Como administrador (Anderson), quero poder fazer upload de um video demonstrativo,
visualizar o preview e remover o video de cada colecao diretamente no painel admin,
para manter o conteudo atualizado sem depender do desenvolvedor.

## Dev Notes

### Localizacao no admin/public/index.html

Adicionar uma nova secao "Video demonstrativo" no editor de colecao, apos a secao
de manual e antes do botao "Salvar".

### UI Components

1. **Label**: "Video demonstrativo" com icone de video (SVG inline ou emoji)

2. **Estado sem video** (`videoUrl` vazio):
   - Input file accept="video/mp4"
   - Texto: "Arraste ou selecione um video MP4 (max 50 MB)"
   - Botao "Enviar video"

3. **Estado com video** (`videoUrl` nao vazio):
   - Player `<video>` com controls, preload="metadata", width 100%
   - Botao "Remover video" (vermelho, com confirmacao)

4. **Estado de upload em progresso**:
   - Spinner + texto "Enviando video..."
   - Desabilitar botao durante upload

### JavaScript functions

```js
async function uploadVideo(slug) {
  const input = document.getElementById(`video-input-${slug}`);
  const file = input.files[0];
  if (!file) return;
  if (file.size > 50 * 1024 * 1024) {
    alert("Video deve ter no maximo 50 MB.");
    return;
  }
  // show loading state
  const fd = new FormData();
  fd.append("file", file);
  const res = await fetch(`/api/collections/${slug}/video`, { method: "POST", body: fd });
  const data = await res.json();
  if (!res.ok) {
    alert(data.error);
    return;
  }
  // refresh collection data
  await loadCollections();
}

async function deleteVideo(slug) {
  if (!confirm("Remover o video demonstrativo?")) return;
  const res = await fetch(`/api/collections/${slug}/video`, { method: "DELETE" });
  if (!res.ok) {
    const d = await res.json();
    alert(d.error);
    return;
  }
  await loadCollections();
}
```

### Integracao com render existente

Na funcao que renderiza o editor de colecao (provavelmente `renderCollectionEditor`
ou similar), adicionar a secao de video baseada no valor de `col.videoUrl`.
