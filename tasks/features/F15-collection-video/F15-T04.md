# F15-T04 — Frontend: video player na pagina de colecao

**Wave:** 2
**Status:** planned
**Depends on:** F15-T01

## User Story

Como visitante do site, quero ver um video demonstrativo de cada colecao na pagina
de detalhes, para ter uma visao mais rica e dinamica das cartas antes de encomendar.

## Dev Notes

### Localizacao no `src/routes/colecoes.$slug.tsx`

Adicionar secao de video **apos** a secao de amostras do deck e links de referencia,
e **antes** do CTA "Quer esse deck?" (WhatsApp).

### Condicao de exibicao

Renderizar apenas quando `collection.videoUrl` nao for string vazia.

### Markup

```tsx
{collection.videoUrl && (
  <div className="mb-12">
    <h2 className="mb-6 text-2xl">Veja o deck em acao</h2>
    <div className="overflow-hidden rounded-lg border border-border/50">
      <video
        src={collection.videoUrl}
        controls
        preload="metadata"
        controlsList="nodownload"
        onContextMenu={(e) => e.preventDefault()}
        className="w-full"
        playsInline
      >
        Seu navegador nao suporta o elemento de video.
      </video>
    </div>
    <p className="mt-3 text-xs text-muted-foreground/60">
      Video demonstrativo — qualidade real das cartas pode variar.
    </p>
  </div>
)}
```

### Atributos importantes

- `controls` — controles nativos do browser
- `preload="metadata"` — carrega so metadados, nao o video inteiro
- `controlsList="nodownload"` — esconde botao de download (Chrome)
- `onContextMenu preventDefault` — impede menu de contexto (mesma protecao das imagens)
- `playsInline` — evita fullscreen automatico em mobile
- Sem `autoplay` — video so toca quando o usuario clicar

### SEO (opcional, baixa prioridade)

Nao adicionar VideoObject JSON-LD nesta versao. Pode ser considerado em feature futura.
