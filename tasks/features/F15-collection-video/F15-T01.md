# F15-T01 — Data model: adicionar videoUrl ao tipo Collection

**Wave:** 0
**Status:** planned
**Depends on:** —

## User Story

Como desenvolvedor, preciso que o modelo de dados suporte um campo `videoUrl` em cada
colecao, para que as demais tasks possam consumir e manipular esse campo.

## Dev Notes

### 1. `src/lib/store-data.ts`

Adicionar `videoUrl: string` ao type `Collection` (apos `manualUrl`).

### 2. `src/data/collections.json`

Adicionar `"videoUrl": ""` em cada colecao existente (castlevania, cavaleiros-do-zodiaco,
final-fantasy-vii).

### 3. `admin/src/server.ts`

Adicionar `videoUrl: string` ao type `Collection` local (apos `manualUrl`).

### 4. `admin/src/lib/paths.ts`

Adicionar export:
```ts
export const VIDEOS_DIR = resolve(PROJECT_ROOT, "public/videos/decks");
```

### 5. MIME type no server.ts

Adicionar `.mp4: "video/mp4"` ao objeto `MIME_TYPES` para servir videos corretamente.

## Acceptance Criteria

- [ ] Type `Collection` em store-data.ts inclui `videoUrl: string`
- [ ] Todas as colecoes em collections.json possuem `"videoUrl": ""`
- [ ] Type `Collection` em server.ts inclui `videoUrl: string`
- [ ] `VIDEOS_DIR` exportado de paths.ts
- [ ] `.mp4` no MIME_TYPES do server
- [ ] `bun run build` sucesso

## Testing

- Validar que build compila sem erros de tipo
- Verificar que collections.json e um JSON valido com videoUrl em cada item
