# Task F14-T04 — Sanitise existing collections.json (remove any stale cache-bust)

**Feature:** F14
**Wave:** 2
**Type:** backend
**Depends on:** F14-T02
**Status:** planned

## User Story

As a developer, I want collections.json to contain only clean paths with no query strings, so that git history stays clean and Vite bundles consistent data.

## Objective

Ensure `src/data/collections.json` has no `?v=<timestamp>` suffixes on any image path. This is a data-cleanup task to handle any stale cache-bust that may have been committed before F14-T02 was deployed.

## Dev Notes

### File: `src/data/collections.json`

### Current state

As of the latest commit, collections.json has clean paths (no `?v=`). However, between commits the file may have acquired cache-bust strings from the cover upload endpoint (Bug 2). This task ensures the data is clean.

### What to do

1. Read `src/data/collections.json`
2. For each collection entry, strip any `?v=...` from the `image` field:
   ```
   col.image = col.image.split("?")[0]
   ```
3. Also strip from each entry in `sampleImages` array (defensive, even though deck images don't currently get cache-bust):
   ```
   col.sampleImages = col.sampleImages.map(img => img.split("?")[0])
   ```
4. Write back only if any changes were made
5. If changes were made, verify `bun run build` still succeeds

### Verification approach

This can be done as a simple check+fix in the developer's implementation. If the file is already clean (which it currently is in git), the task is a no-op but confirms the invariant.

### Alternative: Add a startup sanitiser in server.ts

As a defensive measure, add a one-time cleanup at server startup in `admin/src/server.ts`. Place it after the git config block (around line 750), before the `console.log` and `Bun.serve`:

```typescript
// One-time cleanup: strip query strings from persisted image paths
{
  const cols = readJson<Collection[]>(COLLECTIONS_JSON);
  let dirty = false;
  for (const col of cols) {
    const cleanImage = col.image.split("?")[0];
    if (cleanImage !== col.image) { col.image = cleanImage; dirty = true; }
    const cleanSamples = col.sampleImages.map((s) => s.split("?")[0]);
    if (JSON.stringify(cleanSamples) !== JSON.stringify(col.sampleImages)) {
      col.sampleImages = cleanSamples;
      dirty = true;
    }
  }
  if (dirty) {
    writeJson(COLLECTIONS_JSON, cols);
    console.log("[startup] Sanitised query strings from collections.json");
  }
}
```

This ensures that even if old data was committed with `?v=`, the server cleans it up on first boot.
