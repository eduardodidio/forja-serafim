# Task F14-T01 — Add processCoverImage() to image-processor.ts

**Feature:** F14
**Wave:** 0
**Type:** backend
**Depends on:** (none)
**Status:** planned

## User Story

As an admin, I want uploaded cover images to be properly converted to JPEG format via sharp, so that covers render correctly on the first upload regardless of the original format (PNG, WebP, etc.).

## Objective

Create a new `processCoverImage()` function in image-processor.ts that converts images to JPEG and resizes them, but does NOT apply watermark (Saruman governance condition).

## Dev Notes

- **File:** `admin/src/lib/image-processor.ts`
- The existing `processImage()` (line 23-39) does: sharp resize to 600px + watermark SVG overlay + JPEG conversion at quality 80
- The new `processCoverImage()` must:
  1. Use sharp to read the input file
  2. Resize to max width **1200px** (covers are wider/promotional, not card-sized)
  3. Use `withoutEnlargement: true` (same pattern as processImage, line 28)
  4. Convert to JPEG at quality 85 (slightly higher than cards since covers are promotional)
  5. **NO watermark** — do NOT call `composite()` or `createWatermarkSvg()`
  6. Write to outputPath via `.toFile(outputPath)`
- Export the new function alongside the existing `processImage`

### Constants to add

```
const COVER_MAX_WIDTH = 1200;
const COVER_QUALITY = 85;
```

### Function signature

```typescript
export async function processCoverImage(inputPath: string, outputPath: string): Promise<void>
```

### Pattern to follow

Mirror the structure of `processImage()` (lines 23-39) but skip lines 30-33 (watermark creation) and line 36 (composite). The function body should be approximately:

```
const image = sharp(inputPath);
const metadata = await image.metadata();
const resizeWidth = Math.min(COVER_MAX_WIDTH, metadata.width ?? COVER_MAX_WIDTH);
await image
  .resize({ width: resizeWidth, withoutEnlargement: true })
  .jpeg({ quality: COVER_QUALITY })
  .toFile(outputPath);
```
