**Wave:** 1
**Type:** frontend
**Depends on:** (none)

## User Story

As an admin, I want to see a loading indicator while a cover image is uploading, so that I know the operation is in progress and don't try to upload again.

## Objective

Show a loading spinner overlay on the cover preview area during upload, then refresh with the new image on success.

Add loading state management:

```javascript
async function uploadCover(slug, input) {
  const file = input.files[0];
  if (!file) return;

  input.disabled = true;

  // Show loading spinner on cover preview
  const preview = document.getElementById(`cover-preview-${slug}`);
  let spinner = null;
  if (preview) {
    preview.classList.add("cover-loading");
    spinner = document.createElement("div");
    spinner.className = "cover-spinner";
    preview.appendChild(spinner);
  }

  toast("Enviando capa...");

  try {
    const fd = new FormData();
    fd.append("file", file);

    const res = await apiFetch(`${API}/api/collections/${slug}/cover`, {
      method: "POST",
      body: fd,
    });

    if (!res.ok) {
      toast("Erro ao enviar capa.", "error");
      return;
    }

    toast("Capa atualizada!");
    input.value = "";
    await loadCollections();
    // Refresh the cover preview inside the edit modal
    const col = collections.find((c) => c.slug === slug);
    if (col) {
      const updatedPreview = document.getElementById(`cover-preview-${col.slug}`);
      if (updatedPreview) {
        const img = updatedPreview.querySelector("img");
        if (img) {
          img.style.display = "";
          img.src = col.image;
        }
      }
    }
  } finally {
    // Remove loading state
    if (preview) {
      preview.classList.remove("cover-loading");
      if (spinner && spinner.parentNode) spinner.parentNode.removeChild(spinner);
    }
    input.disabled = false;
  }
}
```

### Key points

- The cover preview container in the edit modal has id `cover-preview-${slug}` (line 1478)
- The `cover-loading` class adds a dark overlay via `::after` pseudo-element
- The spinner is a real DOM element (not pseudo) so it appears above the overlay
- Both are cleaned up in `finally` block to handle both success and error
- After `loadCollections()` the modal content may be re-rendered, but the spinner cleanup is safe (checks parentNode)
