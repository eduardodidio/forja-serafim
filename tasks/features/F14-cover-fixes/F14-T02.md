**Feature:** F14

**Type:** backend
**Depends on:** F14-T01

## User Story

As an admin, I want cover uploads to go through sharp processing and cache-bust to only appear at serve-time, so that covers always render correctly and collections.json stays clean for git.

## Objective

Two changes in server.ts: (1) cover upload endpoint uses `processCoverImage()` instead of raw `Bun.write()`, and (2) GET /api/collections injects `?v=<mtime>` at serve-time instead of persisting it in JSON.

const tmpPath = join(tmpDir, `${slug}-tmp${extname(file.name) || '.jpg'}`);
const buffer = Buffer.from(await file.arrayBuffer());

### Change 4: GET /api/collections injects serve-time cache-bust (line 262-263)

Current code:
```typescript
if (path === "/api/collections" && method === "GET") {
  return json(readJson<Collection[]>(COLLECTIONS_JSON), 200, req);
}
```

Replace with:
```typescript
if (path === "/api/collections" && method === "GET") {
  const collections = readJson<Collection[]>(COLLECTIONS_JSON);
  // Inject serve-time cache-bust for image URLs
  for (const col of collections) {
    // Cover image
    const coverPath = join(PUBLIC_DIR, col.image.replace(/^\//, ""));
    if (existsSync(coverPath)) {
      const mtime = statSync(coverPath).mtimeMs;
      col.image = `${col.image.split("?")[0]}?v=${Math.floor(mtime)}`;
    }
    // Sample images
    col.sampleImages = col.sampleImages.map((img) => {
      const imgPath = join(PUBLIC_DIR, img.replace(/^\//, ""));
      if (existsSync(imgPath)) {
        const mtime = statSync(imgPath).mtimeMs;
        return `${img.split("?")[0]}?v=${Math.floor(mtime)}`;
      }
      return img;
    });
  }
  return json(collections, 200, req);
}
```

**Note:** `PUBLIC_DIR` is already defined on line 711 (`join(PROJECT_ROOT, "public")`). Move its declaration up to the top of the file (after line 23) so it is available within the API handler. Currently it is defined inside the static file serving block near the bottom.
