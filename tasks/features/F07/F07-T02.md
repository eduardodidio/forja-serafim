# Task F07-T02 — UI: Grid gerenciavel de sample images no edit

**Feature:** F07
**Wave:** 1
**Type:** frontend
**Depends on:** F07-T01
**Status:** planned

## User Story

As the store owner, I want to see my sample images in a visual grid with remove and reorder buttons, so that I can easily manage which cards are displayed.

## Objective

Substituir o scroll horizontal de thumbnails por um grid 3x2 interativo no modal de edicao.

## Dev Notes

### Localizacao
- File: `admin/public/index.html` — funcao que renderiza o modal de edicao de colecao

### Grid de samples
- Layout: `grid grid-cols-3 gap-3` (3x2 para 6 cards)
- Cada card mostra:
  - Thumbnail da imagem (aspect-ratio: 2/3, object-cover)
  - Botao X (vermelho) no canto superior direito para remover
  - Setas cima/baixo ou drag handles para reordenar (simplificar com setas up/down)
  - Numero de ordem (1-6) no canto superior esquerdo

### Remover imagem
- Ao clicar X: confirmar com toast "Remover esta imagem?"
- Chamar `DELETE /api/collections/{slug}/images/{filename}`
- Atualizar grid sem recarregar pagina inteira

### Reordenar
- Setas: mover imagem uma posicao para cima ou para baixo no array
- Ao mover: chamar `PUT /api/collections/{slug}/images/reorder` com novo array
- Atualizar grid visualmente

### Upload adicional
- Botao "Adicionar imagens" abaixo do grid
- Desabilitado se ja tem 6 (com tooltip "Maximo de 6 imagens")
- Ao selecionar arquivos, chamar POST existente

## Testing
