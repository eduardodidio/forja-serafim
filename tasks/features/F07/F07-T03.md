# Task F07-T03 — UI: Upload de sample images na criacao de colecao

**Feature:** F07
**Wave:** 1
**Type:** frontend
**Depends on:** F07-T01
**Status:** planned

## User Story

As the store owner, I want to upload sample images while creating a new collection, so that the collection is complete from the start.

## Objective

Adicionar secao de upload de sample images no modal de criacao de colecao.

## Dev Notes

### Localizacao
- File: `admin/public/index.html` — modal de criacao (funcao showAddModal ou similar)

### Nova secao no modal de criacao
- Adicionar tab/secao "Amostras" apos "Links"
- Upload zone com drag & drop (reusar estilo .upload-zone existente)
- Preview das imagens selecionadas antes de enviar (thumbnails locais via FileReader)
- Maximo 6 arquivos

### Fluxo
1. Usuario preenche dados da colecao + seleciona ate 6 imagens
2. Ao clicar "Criar":
   a. POST /api/collections (cria colecao com sampleImages: [])
   b. Se tem imagens: POST /api/collections/{slug}/images com FormData
   c. Se tem capa: POST /api/collections/{slug}/cover
3. Exibir progresso (spinner ou barra)
4. Ao finalizar, fechar modal e atualizar lista

### Preview local
- Usar FileReader.readAsDataURL para preview
- Grid 3x2 de previews com botao X para remover antes de enviar
- Contador: "3/6 imagens selecionadas"

## Testing

- Manual: criar colecao com 6 imagens de uma vez
- Manual: criar colecao com 0 imagens (deve funcionar)
- Manual: tentar selecionar mais de 6 (deve limitar)

## Acceptance criteria

- [ ] Modal de criacao tem secao de upload de amostras
- [ ] Preview local das imagens antes de enviar
- [ ] Maximo 6 imagens validado no frontend
- [ ] Colecao criada com sample images em um fluxo unico
