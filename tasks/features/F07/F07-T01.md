# Task F07-T01 — API: DELETE image individual + PUT reorder

**Feature:** F07
**Wave:** 0
**Type:** backend
**Depends on:** (none)
**Status:** planned

## User Story

As the store owner, I want to remove a specific sample image or reorder sample images via the admin panel, so that I can curate exactly which cards are shown and in what order.

## Objective

Adicionar dois novos endpoints na API do admin para gerenciar sample images.

## Dev Notes

### Endpoint DELETE image individual
- File: `admin/src/server.ts`
- Route: `DELETE /api/collections/:slug/images/:filename`
- Logica:
  1. Encontrar colecao pelo slug
  2. Construir path completo: `/images/decks/{slug}/{filename}`
  3. Remover do array `sampleImages`
  4. Deletar arquivo fisico de `public/images/decks/{slug}/{filename}`
  5. Salvar collections.json
  6. Retornar colecao atualizada

### Endpoint PUT reorder
- Route: `PUT /api/collections/:slug/images/reorder`
- Body: `{ "sampleImages": ["/images/decks/slug/a.jpg", "/images/decks/slug/b.jpg", ...] }`
- Logica:
  1. Validar que todos os paths existem no array atual (nao aceitar paths novos)
  2. Substituir `sampleImages` pelo novo array ordenado
  3. Salvar collections.json
  4. Retornar colecao atualizada

### Validacao de limite
- No endpoint POST /api/collections/:slug/images (upload existente):
  - Verificar `c.sampleImages.length + files.length <= 6`
  - Se exceder, retornar erro 400: "Maximo de 6 imagens de amostra por colecao."

## Testing

- Manual: PUT reorder com array reordenado, verificar nova ordem no JSON
