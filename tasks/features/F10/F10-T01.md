# Task F10-T01 — Script de reprocessamento batch de watermark

**Feature:** F10
**Wave:** 0
**Type:** backend/script
**Depends on:** (none)
**Status:** planned

## User Story

As the store owner, I want all existing sample images to show the correct "Forja Serafim" watermark, replacing the old "A casa do Serafim" branding.

## Objective

Criar script que reprocessa as imagens originais (dos ZIPs) com a watermark correta.

## Dev Notes

### Fonte das imagens originais
- Diretorio: `decks/` — contem ZIPs com as imagens originais SEM watermark
- Extrair imagens de cada ZIP para diretorio temporario
- Mapear nome original → nome no sampleImages (usar mesma logica de sanitizacao do image-processor)

### Script
- File: `admin/src/scripts/rewatermark.ts` (novo)
- Fluxo:
  1. Ler collections.json para obter slugs e sampleImages
  2. Para cada colecao:
     a. Encontrar ZIP correspondente em `decks/` (match por nome/slug)
     b. Extrair ZIP para tmp dir
     c. Para cada imagem em sampleImages:
        - Encontrar imagem original correspondente no ZIP extraido
        - Reprocessar com `processImage()` (que ja usa "Forja Serafim")
        - Sobrescrever em `public/images/decks/{slug}/{name}.jpg`
  3. Limpar tmp dirs
- Executavel via: `bun run admin/src/scripts/rewatermark.ts`

### Mapeamento de nomes
- As imagens no ZIP podem ter nomes diferentes dos sanitizados
- Estrategia: aplicar mesma funcao de sanitizacao nos nomes do ZIP para fazer match
- Se nao encontrar match exato, logar warning e pular

### Fallback
- Se nao conseguir extrair do ZIP, reprocessar a imagem atual (ja tem watermark errada, mas pelo menos tera a nova)
- A watermark antiga sera parcialmente coberta pela nova — melhor que nada

## Testing

- Manual: rodar script em dry-run mode (--dry-run flag) para listar mapeamentos
- Manual: rodar script e verificar imagens geradas

## Acceptance criteria

- [ ] Script criado e executavel com bun
- [ ] Mapeia corretamente imagens do ZIP → paths em sampleImages
- [ ] Reprocessa com processImage() (watermark "Forja Serafim")
- [ ] Loga progresso e warnings
