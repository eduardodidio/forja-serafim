# F04-T02 — Generate favicon from new logo

**Wave:** 0
**Status:** planned
**Depends on:** none (can run in parallel with T01 — logo file available)

## User Story

As a visitor, I want to see the Forja Serafim logo as the browser favicon
and PWA icon so the brand identity is consistent.

## Dev Notes

### Input
- `C:/Workspace/forja-serafim/logoForjaSerafim.jpeg` — 1024x1024 JPEG, gold
  seraph with anvil and flame on dark background

### Output files (all in `public/`)
- `favicon.png` — 512x512 PNG (PWA + general use)
- `favicon.ico` — 48x48 ICO (browser tab)
- `favicon.svg` — NOT regenerated (remove or keep as-is; PNG is sufficient)

### Tools
Use `sharp` (already in admin dependencies) or a simple script:
```typescript
import sharp from 'sharp';

// 512px for PWA
await sharp('logoForjaSerafim.jpeg')
  .resize(512, 512)
  .png()
  .toFile('public/favicon.png');

// 48px for ICO (save as PNG, rename — browsers accept PNG favicons)
await sharp('logoForjaSerafim.jpeg')
  .resize(48, 48)
  .png()
  .toFile('public/favicon.ico');
```

Alternatively use an ICO generator if proper .ico format is needed.
