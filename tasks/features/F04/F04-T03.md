# F04-T03 — Rebrand config files (package.json, render.yaml, lockfiles)

**Wave:** 1
**Status:** planned
**Depends on:** F04-T01

## User Story

As the developer, I want all config/manifest files to reflect the new
"forja-serafim" name so package managers and deploy platforms use the
correct identity.

## Dev Notes

### Files to update

1. **`package.json`**
   - `"name": "casa-do-serafim"` -> `"name": "forja-serafim"`

2. **`admin/package.json`**
   - `"name": "casa-do-serafim-admin"` -> `"name": "forja-serafim-admin"`

3. **`render.yaml`**
   - `name: casa-do-serafim` -> `name: forja-serafim`
   - `name: serafim-admin` -> `name: forja-serafim-admin`

4. **Lockfiles** — regenerate rather than manually editing:
   ```bash
   rm -f bun.lock package-lock.json
   bun install
   cd admin && rm -f bun.lock && bun install && cd ..
   ```

## Testing

- [ ] `package.json` name is `"forja-serafim"`
- [ ] `admin/package.json` name is `"forja-serafim-admin"`
- [ ] `render.yaml` service names are `forja-serafim` and `forja-serafim-admin`
- [ ] `bun install` succeeds in root and admin/
- [ ] No references to `casa-do-serafim` in package.json or render.yaml
