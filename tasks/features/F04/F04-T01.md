# F04-T01 — Copy codebase to new repo (preserving git history)

**Wave:** 0
**Status:** planned
**Depends on:** none

## User Story

As the developer, I want to migrate the entire codebase (with full git history)
from `serafim-arcana-forge` to `forja-serafim` so that the new repo becomes
the single source of truth.

## Dev Notes

### Strategy: preserve history via adding old remote

1. In `C:/Workspace/forja-serafim`, add the old repo as a remote:
   ```bash
   cd C:/Workspace/forja-serafim
   git remote add old-origin https://github.com/eduardodidio/serafim-arcana-forge.git
   git fetch old-origin
   ```

2. Reset main to old-origin/main (since forja-serafim has no commits yet):
   ```bash
   git reset --hard old-origin/main
   ```

3. Update origin remote to point to forja-serafim:
   ```bash
   git remote remove old-origin
   ```

4. Verify: `git log --oneline -10` should show all history from serafim-arcana-forge.

5. Copy the logo file `logoForjaSerafim.jpeg` to the repo root (it was already
   there before the reset, so re-add it if needed — save a backup first).

### Important
- Back up `logoForjaSerafim.jpeg` BEFORE the reset (it will be overwritten)
- Do NOT push yet — wait until all rebrand tasks are done
- The old repo `serafim-arcana-forge` stays untouched as archive
