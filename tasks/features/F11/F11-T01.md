# Task F11-T01 — Componente Card3DTilt + CSS foil shimmer

**Feature:** F11
**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a visitor, I want to see premium 3D card effects when hovering over sample cards, making the browsing experience feel like handling real cards.

## Objective

Criar componente Card3DTilt e CSS de efeitos holograficos, portando do projeto TCG-market-intelligence.

## Dev Notes

### Dependencia

- Instalar: `bun add react-parallax-tilt`
- Versao: ^1.7.x

### Componente Card3DTilt

- File: `src/components/card-3d-tilt.tsx`
- Props:
  - `children: React.ReactNode`
  - `foil?: boolean` (default true)
  - `glowBorder?: boolean` (default false)
  - `tiltMaxAngle?: number` (default 12)
  - `scale?: number` (default 1.05)
  - `className?: string`
- Implementacao:
  - Wrapper com react-parallax-tilt (Tilt component)
  - Config: perspective=1000, transitionSpeed=300
  - Se foil: glareEnable=true, glareMaxOpacity=0.35
  - Mouse tracking via refs (--mouse-x, --mouse-y CSS vars)
  - Classes condicionais: foil-shimmer, foil-shimmer--interactive, foil-shimmer--glow
  - Respeitar prefers-reduced-motion

### CSS foil-shimmer

- File: `src/styles/foil-shimmer.css`
- Pseudo-element ::before — specular highlight (radial-gradient follows mouse)
- Pseudo-element ::after — rainbow holographic (linear-gradient, color-dodge)
- Animacao foil-shift: 3.5s ease-in-out infinite (quando nao interativo)
- Modo interativo: gradient segue mouse position
- Glow border: box-shadow com hue baseado em --mouse-x
- @media prefers-reduced-motion: desabilitar animacoes

### Importar CSS

- No `src/styles.css`: adicionar `@import "./styles/foil-shimmer.css";`
- Ou importar diretamente no componente

### Golden glow (opcional, aproveitar identidade do site)

- Adaptar treasure-glow do TCG para usar cores douradas do Forja Serafim
- Pulsing glow com oklch(0.75 0.09 82) em vez de amber
