# Task F11-T03 — Integrar no lightbox + polish final

**Feature:** F11
**Wave:** 2
**Type:** frontend
**Depends on:** F11-T02
**Status:** planned

## User Story

As a visitor, I want the full-screen lightbox to also have the 3D card effect with enhanced glow, making the preview feel premium.

## Objective

Adicionar Card3DTilt com glow border no lightbox e fazer polish geral.

## Dev Notes

### Lightbox
- Encontrar componente de lightbox (provavelmente em `src/components/` ou inline em colecoes.$slug.tsx)
- Envolver imagem ampliada com `<Card3DTilt foil glowBorder tiltMaxAngle={18} scale={1.08}>`
- Glow border com cor dourada (adaptar hue do box-shadow para gold)

### Polish
- Verificar performance: 3D + shimmer nao deve causar jank
  - Se necessario, usar will-change: transform no Tilt wrapper
- Verificar que efeito funciona com imagens de diferentes tamanhos
- Ajustar intensidade do shimmer se necessario (opacity dos pseudo-elements)
- Testar com imagens reais do projeto (watermarked)

### Golden glow adaptado
- No foil-shimmer.css, adicionar variante dourada:
  ```css
  .foil-shimmer--gold::after {
    /* Gradiente com tons dourados em vez de rainbow completo */
    background: linear-gradient(
      calc(135deg + (var(--mouse-x) - 0.5) * 60deg),
      transparent 10%,
      oklch(0.85 0.06 85 / 0.15) 25%,
      oklch(0.75 0.09 82 / 0.25) 40%,
      oklch(0.65 0.12 75 / 0.3) 55%,
      oklch(0.75 0.09 82 / 0.25) 70%,
      transparent 90%
    );
  }
  ```
- Usar variante gold nas sample images, rainbow no lightbox (ou vice-versa)
