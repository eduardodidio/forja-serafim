# Task F11-T02 — Integrar Card3DTilt nas sample images

**Feature:** F11
**Wave:** 1
**Type:** frontend
**Depends on:** F11-T01
**Status:** planned

## User Story

As a visitor, I want the sample card images on collection pages to have the 3D holographic effect when I hover over them.

## Objective

Envolver as sample images na pagina de colecao com o componente Card3DTilt.

## Dev Notes

### Localizacao

- File: `src/routes/colecoes.$slug.tsx`
- Encontrar o grid de sample images (grid gap-4 sm:grid-cols-2 lg:grid-cols-3)

### Integracao

- Importar Card3DTilt
- Envolver cada `<img>` de sample com `<Card3DTilt foil>`
- Manter estilizacao existente (art-frame class pode conflitar com tilt — avaliar)
- Se art-frame conflitar (transform, overflow), remover art-frame e usar apenas Card3DTilt
- Manter protecao de imagem (draggable=false, onContextMenu disabled)

### Ajustes de layout

- Card3DTilt precisa de overflow:hidden no wrapper (ja vem do Tilt)
- Aspect ratio da carta: manter 2/3 (MTG card ratio)
- Border-radius: usar radius do design system

### Mobile/touch

- react-parallax-tilt suporta touch nativamente
- Verificar que funciona com swipe/scroll sem interferir

## Testing

- Manual: hover em cada carta na pagina de colecao
- Manual: verificar efeito 3D + shimmer
- Manual: testar em mobile (touch tilt)
- Manual: verificar que protecao de imagem ainda funciona

## Acceptance criteria

- [ ] Sample images tem efeito 3D tilt
- [ ] Shimmer holografico funcional
- [ ] Layout e aspect ratio mantidos
- [ ] Protecao de imagem preservada
