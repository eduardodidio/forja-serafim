# F03-T02: PWA — manifest, service worker, favicon set

**Wave:** 1 | **Type:** frontend | **Status:** done | **Depends on:** T01

## User Story

Como cliente, quero instalar o site no meu celular como um app para acessar
rapidamente as colecoes sem abrir o navegador.

## Dev Notes

### manifest.json
- name: "A Casa do Serafim"
- short_name: "Serafim"
- theme_color: "#d4a853" (gold)
- background_color: "#12121f" (deeper)
- display: "standalone"
- icons: 192x192 e 512x512 (gerar a partir do logo)
- start_url: "/"
- scope: "/"

### Service Worker
- Estrategia cache-first para assets estaticos (imagens, CSS, JS)
- Network-first para dados JSON (collections, testimonials)
- Offline fallback page simples ("Voce esta offline")

### Favicon set
- favicon.ico (16x16, 32x32)
- apple-touch-icon.png (180x180)
- favicon-192.png, favicon-512.png
- Cores: fundo escuro (#12121f) com estrela dourada

### Link tags no head
- `<link rel="manifest" href="/manifest.json">`
- `<link rel="apple-touch-icon" href="/apple-touch-icon.png">`
- `<meta name="theme-color" content="#d4a853">`
