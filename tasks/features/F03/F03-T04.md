# F03-T04: Animacoes de entrada com Intersection Observer

**Wave:** 2 | **Type:** frontend | **Status:** done | **Depends on:** T01

## User Story

Como visitante, quero que os elementos da pagina aparecam com animacoes suaves
conforme eu rolo, dando uma sensacao premium e profissional ao site.

## Dev Notes

### Hook useReveal
- Custom hook `useReveal()` que usa IntersectionObserver
- Retorna ref + classe CSS condicional
- Trigger: quando o elemento entra 20% na viewport
- Anima apenas uma vez (unobserve apos trigger)

### Animacoes
- Cards de colecao: fade-up com stagger (delay incremental)
- Secao features: fade-in sequencial
- Depoimentos: fade-left / fade-right alternado
- CTA final: fade-up
- Titulos de secao: fade-in

### CSS
- Classes: `.reveal`, `.reveal-up`, `.reveal-left`, `.reveal-right`
- Base: opacity 0, transform translateY(20px) ou translateX(20px)
- Ativo: opacity 1, transform none
- Transition: 0.6s ease-out com delay variavel

### Respeitar prefers-reduced-motion
- Se `prefers-reduced-motion: reduce`, desabilitar animacoes (mostrar tudo imediatamente)

## Files affected

- `src/hooks/useReveal.ts` — novo hook (ou inline em utils)
- `src/routes/index.tsx` — aplicar animacoes nas secoes
- `src/routes/colecoes.index.tsx` — animacoes nos cards
- `src/routes/colecoes.$slug.tsx` — animacoes na galeria
- CSS global (em __root.tsx ou style tag) — classes de animacao

## Acceptance criteria

- [ ] Cards de colecao animam ao entrar na viewport
- [ ] Secao features anima sequencialmente
- [ ] Depoimentos animam com direcao alternada
- [ ] prefers-reduced-motion respeitado
- [ ] Sem jank ou layout shift durante animacao
- [ ] Animacao dispara apenas uma vez por elemento

## Testing

- Scroll pela pagina e verificar animacoes
- Desabilitar animacoes no sistema e verificar que conteudo aparece imediato
- Verificar que nao ha flash de conteudo invisivel (CLS)
- Testar em viewport pequena (mobile)
