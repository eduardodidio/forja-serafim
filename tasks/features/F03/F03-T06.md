# F03-T06: Pagina 404 customizada

**Wave:** 3 | **Type:** frontend | **Status:** planned | **Depends on:** T01

## User Story

Como visitante que acessou um link quebrado, quero ver uma pagina bonita e util
que me direcione de volta ao site em vez de um erro generico.

## Dev Notes

### Design
- Manter identidade visual (fundo escuro, gold accent)
- Ilustracao: usar icone grande de carta/baralho ou texto estilizado "404"
- Texto: "Esta carta nao esta no seu deck" (tematico MTG)
- Subtexto: "A pagina que voce procura nao existe ou foi removida."
- Botoes:
  - "Ver colecoes" (link para /colecoes)
  - "Voltar ao inicio" (link para /)
  - "Falar no WhatsApp" (link WhatsApp)

### Implementacao
- Criar rota catch-all ou usar o mecanismo de not-found do TanStack Router
- Verificar como TanStack Start trata 404s (provavelmente `__root.tsx` notFoundComponent)

## Files affected

- `src/routes/__root.tsx` — notFoundComponent
- Ou `src/routes/$.tsx` — catch-all route (alternativa)

## Acceptance criteria

- [ ] Acessar /url-inexistente mostra pagina 404 customizada
- [ ] Design coerente com identidade visual do site
- [ ] Links funcionais para colecoes, home e WhatsApp
- [ ] Texto tematico (referencia a MTG)

## Testing

- Acessar /pagina-que-nao-existe
- Acessar /colecoes/deck-inexistente
- Verificar que links na 404 funcionam
- Verificar visual em mobile
