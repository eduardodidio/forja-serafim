# F03-T01: SEO tecnico — meta tags, structured data, sitemap

**Wave:** 0 | **Type:** frontend | **Status:** done | **Depends on:** —

## User Story

Como Anderson, quero que meu site apareca bem no Google e redes sociais para
atrair mais clientes organicamente.

## Dev Notes

### Meta tags (Open Graph + Twitter Card)

- Adicionar em `__root.tsx` ou layout global:
  - `og:title`, `og:description`, `og:image`, `og:url`, `og:type`
  - `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`
- Cada pagina de colecao (`colecoes.$slug.tsx`) deve ter meta tags dinamicas
  com nome e imagem da colecao

### Structured Data (JSON-LD)

- Schema `Organization` na homepage:
  - name: "A Casa do Serafim"
  - type: "Store"
  - url, logo, contactPoint (WhatsApp)
- Schema `Product` em cada pagina de colecao:
  - name, description, image, offers (priceRange informal)
- Schema `BreadcrumbList` nas paginas internas

### Sitemap e robots.txt

- Gerar `public/sitemap.xml` estatico com todas as rotas
- Atualizar `public/robots.txt` com referencia ao sitemap

### Canonical URLs

- Adicionar `<link rel="canonical">` em todas as paginas

## Files affected

- `src/routes/__root.tsx` — meta tags globais, JSON-LD Organization
- `src/routes/index.tsx` — meta tags da home
- `src/routes/colecoes.$slug.tsx` — meta tags dinamicas, JSON-LD Product
- `public/sitemap.xml` — novo
- `public/robots.txt` — atualizar
