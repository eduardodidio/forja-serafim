# F03-T05: Admin UX polish — escape, double-click, error handling, drag-drop

**Wave:** 2 | **Type:** frontend | **Status:** planned | **Depends on:** —

## User Story

Como Anderson, quero que o admin seja robusto e responsivo a erros, sem clicks
acidentais duplicados e com suporte a arrastar arquivos para upload.

## Dev Notes

### Escape fecha modais
- Adicionar event listener global `keydown` para Escape
- Quando modal aberto, Escape chama closeModal()

### Protecao double-click
- Em todas as funcoes async que fazem API calls (addCollection, saveCollection,
  addTestimonial, saveTestimonial, doPublish):
  - Desabilitar botao ao iniciar
  - Reabilitar ao concluir (sucesso ou erro)
- Pattern: setar um flag `isSubmitting` ou desabilitar via DOM

### Error handling no init
- Wrap loadCollections/loadTestimonials/loadSettings em try/catch
- Se falhar, mostrar toast de erro + retry button inline
- Remover skeletons e mostrar mensagem de erro amigavel

### Drag-and-drop real nos uploads
- Nas zonas de upload do modal de criacao (cover):
  - Detectar dragover/dragleave/drop
  - Highlight visual na zona durante drag
  - Aceitar arquivos dropados e processar como se fossem do input
- Nos botoes de upload inline (cover, images, manual):
  - Manter o comportamento atual (click to select)
  - Adicionar drop zone opcional se UX justificar

### Preview de imagens no upload de deck
- Ao selecionar multiplas imagens para upload:
  - Mostrar grid de previews antes de confirmar envio
  - Counter: "X imagens selecionadas"
  - Botao "Enviar" separado do "Selecionar"

## Files affected

- `admin/public/index.html` — todas as melhorias

## Acceptance criteria

- [ ] Escape fecha qualquer modal aberto
- [ ] Nenhum botao de acao pode ser clicado duas vezes durante submissao
- [ ] Erros de carregamento mostram mensagem amigavel + retry
- [ ] Drag-and-drop funciona no upload de capa (modal de nova colecao)
- [ ] Preview grid de imagens antes de upload de deck

## Testing

- Abrir modal e pressionar Escape (deve fechar)
- Click rapido duplo em "Adicionar" (deve processar apenas uma vez)
- Desligar o server e recarregar o admin (deve mostrar erro amigavel)
- Arrastar imagem para a zona de upload de capa
- Selecionar 5 imagens para deck e verificar preview grid
