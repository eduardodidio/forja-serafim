# F01-T06: Extract sample images from deck ZIPs and prepare watermarked assets

**Wave:** 1 | **Type:** infra | **Status:** planned | **Depends on:** T05

## Description

Extract 3-5 sample card images from each deck ZIP. Resize to max 600px wide.
Apply "A Casa do Serafim" watermark (semi-transparent, diagonal, ~60% coverage).
Place in `public/images/decks/{slug}/`. Create `scripts/process-images.ts` using
sharp for future admin tool reuse.
