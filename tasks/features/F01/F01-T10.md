# F01-T10: Scaffold admin tool as a separate local CLI application

**Wave:** 3 | **Type:** infra | **Status:** planned | **Depends on:** T06

## Description

Create `admin/` directory as standalone Bun CLI tool. Commands:
- `add-collection` — interactive prompt to add a new collection
- `edit-collection` — edit existing collection (name, desc, links, price)
- `remove-collection` — remove a collection
- `process-images` — takes raw images folder, applies watermark + resize via sharp

Reads/writes `src/lib/collections.json` (data source for store-data.ts).
Anderson follows README to manage content without developer help.

## Files affected

- `admin/package.json` — create
- `admin/src/cli.ts` — main CLI entry
- `admin/src/process-images.ts` — watermark + resize logic
- `admin/src/manage-collections.ts` — CRUD on data file
- `admin/README.md` — usage instructions for Anderson

## Acceptance criteria

- [ ] `cd admin && bun run cli add-collection` works interactively
- [ ] `process-images` watermarks and resizes correctly
- [ ] Data changes persist to JSON file read by main site
- [ ] Anderson can follow README to manage content
