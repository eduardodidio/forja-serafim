# The Seraph's Atelier

Crie uma aplicação web moderna, responsiva e com foco em conversão para uma loja de proxies premium de Magic: The Gathering. Nome da loja: A Casa do Serafim Conceito da marca: A Casa do Serafim cria proxies FULL ART profissionais e temáticas para Magic: The Gathering. Cada deck é desenvolvido artesanalmente com identidade visual inspirada em universos famosos como: • Diablo • Castlevania • Cavaleiros do Zodíaco • Senhor dos Anéis • Warcraft • Final Fantasy • Dark Souls • Bloodborne • Elden Ring • Zelda • Felinos • Vampiros • Dragões • Samurai • Cyberpunk • Anime O objetivo é vender arte personalizada para jogadores casuais, Commander e colecionadores.
